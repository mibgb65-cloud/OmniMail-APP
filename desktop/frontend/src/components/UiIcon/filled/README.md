# 邮件分类实心图形

来源：[Heroicons v2.2.0](https://github.com/tailwindlabs/heroicons/tree/v2.2.0/optimized/24/solid)，
仅本地保存下列六个 24×24 solid SVG；不安装额外图标包，不在应用运行时请求远程图标。

| 本地图形           | 分类语义   |
| ------------------ | ---------- |
| inbox.svg          | 全部收件箱 |
| star.svg           | 星标邮件   |
| paper-airplane.svg | 已发送邮件 |
| document-text.svg  | 草稿箱     |
| archive-box.svg    | 归档邮件   |
| trash.svg          | 已删除邮件 |

下载日期：2026-10-27。下载时已校验视框、currentColor 和静态 path 属性；
文件只作为 Morphicons 的图形数据解析，不通过 HTML 注入渲染。
描边图形仍使用现有 Lucide 数据，Morphicons 负责描边与实心之间的区域变形。
