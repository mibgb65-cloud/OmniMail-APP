# OmniMail v0.0.4

Windows x64 当前用户签名安装包，本次本地交付，不代表已发布 GitHub Release。

## 本次内容
- 右侧 AI 面板接入单封邮件摘要、要点、待办和关键信息，待办/信息附原文引文；
  未明确的负责人/日期保持“未明确”，结果需人工核对，不自动执行邮件中的指令。
- AI 设置支持 OpenAI-compatible 接口、模型和输出语言；首次配置默认预填
  `https://api.deepseek.com`、`deepseek-flash`（当前对应 DeepSeek V4.1 Flash），
  需自己的 API Key。已有配置不会自动覆盖，也可手动填入 DeepSeek 预设。
- 官方 DeepSeek 请求显式关闭思考并启用 JSON 输出；通用接口不接收 DeepSeek 专属参数。
  连接测试仅发送固定合成文本，测试/分析可能消耗服务方额度。
- API Key 进入系统凭据库，普通配置只保存引用；更换服务目的地不携带旧密钥。
  明确授权并主动操作后才外发选中邮件标题/正文，不上传附件或邮箱登录凭据。
- 回复建议支持意图与语气，只有点击“采用”才填入撰写区，不覆盖已有未发送内容，
  不设置收件人/主题、不自动发送；用户仍须检查并手动发送。
- 分析结果本地缓存，支持主动重新生成及二次确认清理；换邮件、配置变化或关闭面板取消旧任务，
  迟到结果不能串入其他邮件，清理不删除邮件、附件、配置或密钥。
- B 站工具栏翻译保持独立，新增分段进度、限流冷却提示；
  修复响应体超时/断流误报格式错误，并补齐撤销授权、缓存清理与取消恢复回归。

## 兼容与数据
- 沿用 0.0.3 的安装身份及升级规则，覆盖升级保留安装/数据目录、安装语言与快捷方式选择。
- 本次不新增数据库迁移；新增 `ai-config.json` 和 `ai-results/` 位于现有应用数据目录。
  派生缓存包含本机文本，不宣称静态加密；密钥不在这些文件中。
- 撤销授权与清理本机缓存是不同操作，取消请求不能撤回第三方已收到的文本。
- 当前 AI 正文限制为标题 4 KiB、正文 32 KiB；不完整/超限正文拒绝处理，不静默截断后冒充完整成功。
- 安装/卸载会按既有逻辑关闭正在运行的 OmniMail；当前撰写内容不持久化，
  覆盖升级前请先处理未发送内容。

## 已知边界
- 使用 OmniMail 自签名代码签名证书，不是公共 CA 签名，Windows 仍可能提示未知发布者或 SmartScreen。
- 应用内自动更新未启用，仍需手动下载安装包覆盖升级；本轮不自动安装或重启用户程序。
- DeepSeek 官方模型别名可能随服务方更新；没有真实 Key/邮件的公网质量验收，
  不能把本地协议测试当作真实模型效果保证。机器结果始终应核对原文。
- 暂无自动分析、聊天/RAG、附件/OCR、可执行工具或自动发送；单个通用 AI 外发任务并发为 1。
- 未做真实 0.0.3→0.0.4 生产安装覆盖升级、完整原生窗口交互及 macOS/Linux 原生验收。
