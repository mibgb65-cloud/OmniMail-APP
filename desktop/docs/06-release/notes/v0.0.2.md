# OmniMail v0.0.2

Windows x64 当前用户安装包，本次仅本地打包交付，不代表已发布 GitHub Release。

## 本次内容
- 安装与卸载会先关闭正在运行的 OmniMail（包括托盘常驻和“关闭时询问”偏好），
  不再出现“DeleteFile 失败：错误代码 5，拒绝访问”；升级时若关闭过实例，完成页默认勾选启动。
- 侧栏“写邮件”在尚未添加邮箱时只提示“未添加邮箱”，邮箱加载期间显示“加载中”，不再标注“待开发”。
- 主工作区内撰写邮件：保留导航与邮件列表，切换浏览后会话内容仍在，主动放弃才确认清除；发送沿用既有纯文本 SMTP 桥接。
- “我的邮箱”增加平铺与服务商分组两种浏览方式，可进入服务商组再选具体邮箱，保留状态点、单账号重试与键盘操作。
- 邮件标题与正文手动翻译、目标语言选择及工具栏“原／译”切换，本地缓存译文；不自动上传邮件，不默认开启云端翻译。
- 自定义服务商连接参数可保存为本地模板，下次在选择页直接复用；模板不含账号、密码或令牌。
- 设置页补齐七个分类：邮箱设置、通知设置、邮件查看、AI 设置、存储情况、关于、软件更新；
  存储情况读取当前数据目录的真实字节数，未接入能力明确说明而不是给出无效开关。
- 外观改为紧凑三段胶囊（亮／暗／跟随系统），关闭主窗口可选询问／退出／后台，Windows 托盘可恢复与退出；
  未实现开机自启动。
- 邮件图片三种策略与关闭行为选择器视觉统一；账号管理列表显示服务商品牌图标，自定义服务商沿用通用图标。
- 主窗口最小宽度限制，避免正文被挤成逐词换行；左侧邮箱栏加宽到 240px；邮箱状态点去掉悬停底色；LINUX DO 图标改用透明版本。
- 设置“关于”页不再使用嵌套圆角卡片，改为细线分区的扁平排版。

## 兼容与数据
- 沿用 0.0.1 的安装身份与数据目录选择，覆盖升级保留原程序目录、数据位置、安装语言与快捷方式选择，拒绝降级。
- 卸载默认保留邮件数据；数据库迁移沿用既有版本化脚本，升级前保留备份。
- 自定义服务商模板与关闭偏好属于新增本地配置，位于应用数据目录，不含凭据。

## 已知边界
- 使用 OmniMail 自签名证书，不是公共 CA 发行的代码签名证书，Windows 仍可能提示未知发布者或 SmartScreen 警告。
- 应用内自动检查/下载更新、更新通知与“重启并更新”尚未启用，本版本仍需手动下载安装包覆盖升级。
- 不支持 ARM64、macOS/Linux 安装包，不自动迁移旧独立程序数据，也不自动安装缺失的 WebView2 Runtime。
- 草稿持久化、附件/富文本/抄送、后台发送队列、OAuth 与 IDLE 推送仍未实现。
