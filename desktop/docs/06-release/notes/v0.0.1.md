# OmniMail v0.0.1

Windows x64 当前用户安装包，本次仅本地打包交付，不代表已发布 GitHub Release。

## 本次内容
- 邮件标题、正文手动翻译与目标语言选择，工具栏“原／译”切换、本地译文缓存恢复及响应格式兼容。
- Inno Setup 安装向导支持简体中文和英文，程序与数据位置分离，默认创建桌面快捷方式，不默认登录自启。
- 安装路径安全检查、升级保留原数据位置与语言、拒绝降级；卸载默认保留邮件数据。
- 修正开发运行的通用注册表键被误判为生产安装的问题：生产/开发使用独立安装记录，首次生产安装不继承开发数据。
- 数据和程序目录的原生浏览窗口均支持新建文件夹，选择的路径不自动追加目录名，不需要退出安装器去资源管理器创建。
- 主程序、更新预备助手、卸载器和安装包代码签名，以及带 Ed25519 签名的版本清单和 SHA-256 校验文件。

## 已知边界
- 使用 OmniMail 自签名证书，不是公共 CA 发行的代码签名证书，Windows 仍可能提示未知发布者或 SmartScreen 警告。
- 应用内自动更新的设置、消息通知及草稿/发送保护尚未闭环，本版本不启用自动更新。
- 不支持 ARM64、macOS/Linux 安装包，也不自动迁移旧独立程序的数据或安装缺失的 WebView2 Runtime。
- 安装记录隔离做了定向回归与安装器启动检查；未重跑全量 verify 或执行安装后的邮件业务验收。签名、时间戳和打包必要门禁保留。
