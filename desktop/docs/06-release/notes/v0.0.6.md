# OmniMail v0.0.6

Windows x64 当前用户签名生产安装包，本次本地交付，不代表 GitHub Release。
本版按用户要求直接构建，**本轮没有运行测试或完整 verify**。
来源为当前最新工作树，包含尚未提交的 UI 优化，不仅是包内显示的 Git 基线提交。

## 本次内容
- 重整待办工作台层次：低强调页签、图标工具按钮、真实计数筛选、可操作空态及准确分页，
  区分全局无事项与筛选无结果，不显示无效分页或迟到的旧筛选数据。
- 页签保留选择、设置草稿及滚动位置；关闭有修改时明确放弃，保存中防止误退出。
- 跨邮件分析采用“选择 → 本地校验/核对 → 确认外发”，展示目的地、模型、数量与重试风险；
  授权修订变化阻止旧核对计划，最终启动仍由后端复验。
- 每日设置分范围/计划/权限；保存语义区分启用、普通保存和撤销，
  后台运行时确认停止旧批次的影响。未修改的设置保存不换修订或打断批次。
- 待办编辑宽屏左右对照人工字段与 AI 建议/来源，固定保存操作区；
  删除/放弃使用独立确认，重读建议期间锁定旧表单，来源仍仅作安全文本。

## 升级与数据
- 沿用 schema v6，本轮 UI 优化没有新增数据库迁移；从更早 schema 升级仍先自动备份。
  **旧版不能直接打开升级后的数据库，不要直接降级覆盖。**
- 安装器会关闭运行中的 OmniMail，安装前请先处理未发送邮件；本轮不会替用户安装或重启。
- 每日分析默认关闭，须单独选择范围并授权启用；取消不能撤回已发送文本。
- 保留原来的 DeepSeek 配置、单封分析、待办/运行记录与独立系统凭据存储。

## 已知边界
- 本轮仅构建及交付核对，未运行单测、浏览器/原生交互或完整门禁，
  未做真实数据迁移、生产覆盖升级、托盘连续运行或真实邮件公网质量验收。
- 使用既有 OmniMail 自签名身份，Windows 可能提示未知发布者/SmartScreen，不要求安装根证书。
- 应用内自动更新仍未启用，仍须手动安装；不自动外发、完成事项、移动邮件或发送回信。
