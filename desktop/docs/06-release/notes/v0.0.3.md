# OmniMail v0.0.3

Windows x64 当前用户安装包，本次仅本地打包交付，不代表已发布 GitHub Release。

## 本次内容
- 版本号统一到 0.0.3：把 0.0.2 本地打包期间的三处修复并入同一版本，程序显示版本、安装包名与
  更新清单一致；功能面与 0.0.2 最后一次修复一致，没有新增功能。
- 覆盖安装与卸载会先结束正在运行的 OmniMail（含托盘常驻与“关闭时询问”偏好），
  不再出现“尝试替换现有文件时出错：DeleteFile 失败；错误代码 5，拒绝访问”；
  无法结束时在复制文件前中止并提示，升级关闭过实例时完成页默认勾选“安装完成后启动”。
- 设置“关于”页不再使用嵌套圆角卡片，改为 1px 细线分区的扁平排版：连接区只保留小标题、文字按钮、
  状态行和等宽元数据列，三步引导为“序号＋标题＋说明”的纯文本三列。
- 侧栏“写邮件”按实际可用状态提示：未添加可用邮箱显示“未添加邮箱”，邮箱加载中显示“加载中”，
  不再标注“待开发”；“添加邮箱”禁用态同步改为“加载中”。

## 与 0.0.2 的关系
0.0.1 与 0.0.2 均为本地打包，期间三次重打包分别只带单处修复；0.0.3 是这些修复合入后的
统一版本。若已安装 0.0.2 的任一局部修复包，覆盖安装 0.0.3 即可，数据与安装位置不变。

## 兼容与数据
- 沿用 0.0.1 起的安装身份与数据目录选择，覆盖升级保留原程序目录、数据位置、安装语言与快捷方式选择，拒绝降级。
- 卸载默认保留邮件数据；数据库迁移沿用既有版本化脚本，升级前保留备份。
- 自定义服务商模板、关闭偏好与界面语言偏好位于应用数据目录，不含凭据。
- 安装前强制结束运行实例可能丢失未发送的撰写内容：当前版本不持久化草稿。

## 已知边界
- 使用 OmniMail 自签名证书，不是公共 CA 发行的代码签名证书，Windows 仍可能提示未知发布者或 SmartScreen 警告。
- 应用内自动检查/下载更新、更新通知与“重启并更新”尚未启用，本版本仍需手动下载安装包覆盖升级。
- 不支持 ARM64、macOS/Linux 安装包，不自动迁移旧独立程序数据，也不自动安装缺失的 WebView2 Runtime。
- 草稿持久化、附件/富文本/抄送、后台发送队列、OAuth 与 IDLE 推送仍未实现。
- 本次未在真实生产安装上重跑覆盖升级冒烟；安装器的关闭与替换逻辑由隔离探针验证（TASK-0088）。
