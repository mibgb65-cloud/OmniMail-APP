  内容过长仅滚动内容区，步骤变化不改变外框尺寸。
- 现有设置、添加邮箱、撰写邮件统一接入共用外框；记录后续同类弹窗的接入规范与回归检查。

- 完整保留 TASK-0041/0042 的未提交成果，不提交、不推送、不切分或清理其 Git 状态。

## 初步分析

- 设置目前使用专属 `--settings-dialog-width/height`（900×580）；账号和撰写使用 640px 宽、
  内容自适应高度，且遮罩缺少设置的背景模糊。
- 采用只负责视觉与原生 dialog 属性/引用转发的共用 DialogFrame，保留各业务原有
  showModal、取消、关闭、焦点及请求中止逻辑，避免无关重构。
- i18next 初始资源为 structuredClone；Provider 持有实例，不随资源热更新重建，
  与截图中旧文案/新键名共存的现象吻合，需要失败测试和实际 HMR 验证。
