## 用户需求与范围

- 发件人、收件人分别提供复制邮箱按钮，含多收件人、成功/失败和键盘反馈。
- 移除阅读区底部“正文与 HTML 存储/脚本安全”等技术说明，不再占用正文空间。

## 事实与取舍

- 工作树有 TASK-0051 未提交改动；本任务独立记录，保留所有原改动，不自动提交或归档。
- 当前头信息在 `MailContent.tsx` 直接堆叠文本，时间在第三行；底部通过 `cacheHint` 展示技术说明。
- 当前协议适配器已将收发件人解析为邮箱地址列表，不引入联系人推断或另造 RFC 地址解析器。
  复制仅处理已展示的地址文本，按类型、长度、控制字符和地址基本格式防护；非法/空值保持可选中，
  不调用剪贴板、不猜测或补造地址。
- 原计划复用 Wails 前端 `Clipboard.SetText`；核对锁定 SDK 后发现其 Go 消息处理器丢弃原生 bool 回执，
  因此新增最小 AppBridge 地址复制方法，注入原生 bool 写入能力，失败返回固定标识，不升级运行时。
  浏览器安全环境可用 `navigator.clipboard.writeText`，
  权限/不可用错误统一提示，不读剪贴板、不记录邮箱或底层错误。
- 抽出独立 `MailHeader`，时间常规右对齐，窄宽度下仍右对齐但换到独立行；
  长地址最多两行并保留全文复制，按钮统一 Tooltip 提供完整地址（遵守 1024 字符提示上限），
  不让异常长地址撑高整屏。图标按钮使用既有主题/尺寸 Token。
- 复制完成状态属于当前行/当前邮件，切换不会把旧异步结果展示到新邮件。

## 实现结果

- `MailHeader.tsx/.module.css`：主题独立，元信息左侧收发件人和复制，右侧收件时间。
  窄宽度使用独立右对齐时间行，异常长地址最多两行，Tooltip 和剪贴板保留完整值；
  复制成功不导致头部高度/正文跳动，失败可手动选择，切换行/邮件清除旧反馈。
- `lib/bridge/clipboard.ts`：类型、长度、控制字符及地址基本格式校验，桌面调用生成的
  AppBridge 方法；浏览器使用标准 clipboard 写入，统一错误标识，不读取或记录剪贴板。
- `internal/bridge/clipboard.go`：复用 Go 标准地址解析，检查输入、取消、数量/长度及
  原生 bool 结果；无效输入或原生失败统一返回 COPY_UNAVAILABLE，不升级 Wails 也不吞掉写入失败。
- `internal/app/app.go` 只在装配边界注入 `application.Get().Clipboard.SetText`，
  生成绑定新增 CopyMailAddresses，现有 Version ID/行为不变。
- `MailContent` 替换旧堆叠头部，彻底移除底部技术说明与两语言 cacheHint 无用键；
  保留正文恢复、图片隐私及错误等必要提示。共享图标组件复用已有 Copy/Check。
- 新增 Go/前端安全与交互测试；更新详情页当前实现说明。未改存储语义、schema、依赖或邮箱协议。
