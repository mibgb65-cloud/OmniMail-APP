- 起点为干净工作树，TASK-0030 已归档，当前仅有内部账号仓储，界面仍是禁用占位。
- 优先交付密码/应用授权码的安全接入；服务商 OAuth 需合法注册的客户端配置，

- 大附件按需获取、流式写入；凭据不写前端持久化、数据库或日志。
- 本轮明确授权必要的邮件协议适配与数据库追加迁移；不增加大型框架、不升级前端依赖。

## 实现与验证

## 本轮结果（2026-10-28）

已形成密码/应用授权码的可用首个闭环：

1. 账号选择预设/手动服务器、分别配置 IMAP/SMTP，TLS 认证后保存系统凭据与 SQLite。
2. 启动后轮询、手动同步、账号内互斥/全局 3 连接，成功批次与游标同事务；
   首次优先近端窗口、压缩 UID 搜索跳过空洞，历史批次 5 秒继续。
3. 邮件列表/服务器标志、正文按需解析、附件流式落盘与租约补偿、原生另存新文件；
   HTML 只显示文本，默认不执行或加载远程资源。
4. 纯文本 SMTP 发送，服务器 DATA 接受才报告成功，不确定结果不自动重发；
   断开账号删除凭据并保留可显式查看的离线缓存。
