# TASK-0047 邮件列表信息层级与视觉优化

> 状态：已完成
> 负责人：@Codex | 创建：2026-10-30 | 优先级：P1

## 需求与范围

用户反馈截图中的邮件列表布局难看，希望优化设计。聚焦真实邮件列表的布局、文字层级和交互状态，
保留现有收发、筛选、选择、分页与同步逻辑；不重做阅读区，不添加虚构摘要、联系人照片或邮件操作。

## 分析与取舍

- 开始时 `git status --short` 为空，没有需要保留的既有未提交改动。
- 实际列表在 `MailList.tsx`，复用 `MailContent.module.css`；当前发件人、完整时间、主题纵向堆叠，
  列宽为 `clamp(180px, 21vw, 290px)`，长主题任意换行，选中与悬停相同，未读仅以字重区分。
- 采用轻量分组行：发件人首字占位、发件人与短日期同行、两行主题、未读标记和独立选中态。
  不引入依赖、外部头像请求或新的全局设计系统；继续使用现有主题 Token 和国际化框架。
- 完整发件人、主题及时间保留无障碍名称与全局悬浮提示；日期按当前语言格式化。
- 将列表样式隔离到独立 CSS Module，避免阅读区与状态按钮被列表视觉规则影响。

## 实现结果

- `MailList.tsx` 与独立 `MailList.module.css`：圆角分组行，发件人与短日期同行，
  两行主题固定预留高度；选中填充加侧边线，未读圆点加字重，已读主题降一级对比。
- 列宽改为 `clamp(232px, 24vw, 340px)`，最多占双列区 48%；不超过 260px 时隐藏装饰头像，
  保留发件人和日期空间。相关尺寸放入现有 `tokens.css`，配色跟随现有浅深色 Token。
- 日期使用当前语言，当年省略年份、跨年保留年份，非法日期不调用格式化器；
  空白发件人及主题回退到新增的中英文文案。
- 完整信息放入无障碍名称及统一 Tooltip；Tooltip 按现有 1024 字符上限限制，
  原始邮件数据不改写、筛选仍匹配原文，不将主题作为 HTML 渲染。
- `MailContent.module.css` 移除已迁出的列表规则；阅读区、收发、同步和分页控制器保持不变。
- 新增 5 个组件用例，覆盖双语言信息、非法/空值、跨年和超长不可信内容。
- 更新 `inbox.md` 的当前实现说明。临时脱敏预览脚本、截图与检查 JSON 均在忽略目录 `.task/`，
  不进入项目源代码或业务数据。
