# TASK-0041 邮箱输入匹配服务商与品牌图标

> 状态：已完成 | 归档：2026-10-30
> 负责人：@Codex | 创建：2026-10-29 | 优先级：P1
> 关联：TASK-0039

## 需求与范围

- 为添加邮箱的服务商卡片引入对应品牌图标，保留自定义 IMAP/SMTP 入口。
- 在选择页提供邮箱输入框，根据完整邮箱域名匹配已支持的服务商，继续时进入对应配置；未匹配时进入自定义配置。
- 不再显示“密码只用于认证并保存到系统凭据存储，不写入本地数据库或浏览器存储。”。
- 不更改服务商端点、认证、系统凭据存储、数据库或桥接协议，不新增依赖。

## 分析与方案

- 当前两步向导仅支持手动卡片选择，卡片使用文字占位标识；服务商来自 `Providers`，配置和秘密清理集中在 `useAccountForm`。
- 采用本地静态品牌图标，不向第三方发送邮箱或在运行时请求图标。
- 输入时展示匹配结果，按“继续”或 Enter 再切换步骤，避免输入未完成就跳转；只匹配完整域名，不采用不安全的后缀模糊匹配。
- 保留手选卡片、加载失败重试、键盘焦点、返回清除秘密等现有行为。开始时工作树干净。

- [x] 有效邮箱能识别 Gmail、QQ、163、126；未知域名转自定义，邮箱及登录名自动带入。
