## 需求与范围

- 替换用户截图中的原生 `title` 黑色提示，统一软件内全部同类悬浮提示。
- 提供与应用一致的圆角、边框、阴影、明暗主题及轻量动效，兼顾键盘、禁用控件与窗口边缘。
- 不更改提示文案含义、按钮业务行为、邮件数据或系统原生菜单/窗口外壳。
- 不新增依赖，不修改认证/持久化；保留 TASK-0041 全部既有未提交变更。

## 分析与取舍

- 当前 22 处原生提示声明分布在侧栏、标题栏、工具栏、语言切换、设置/账号弹窗等处，
  服务于复用生成的多个控件。
- 优先采用单一 TooltipHost 与声明式 `data-tooltip`，不包装按钮，避免影响已有动画、
  网格、禁用状态和焦点顺序；保留非 DOM 的 `FolderBubble.title` 业务属性。
- 浮层使用 Portal，模态框内提示进入对应 dialog，避免被 top layer 遮挡；
  用固定定位计算翻转/边缘约束，不靠提升 z-index 穿透原生模态框。
- 悬停短延迟，键盘聚焦可见，允许移入提示，Esc/点击/滚动/失焦关闭；
  保留已有 `aria-describedby`，及时清理计时器、监听与引用。
- 本地 UI skill 的 tooltip 专项检索未命中适用规则；采用通用可访问交互原则与仓库现有 Token，
  不把泛化检索结果当成产品规范。
