# TASK-0045 标准弹窗退出动效

> 状态：已完成 | 归档：2026-10-30
> 负责人：@Codex | 创建：2026-10-29 | 优先级：P1
> 关联：TASK-0043、TASK-0044

## 需求与目标

用户指出设置等同类页面关闭时没有退出动画，突然消失产生闪烁感。
为现有标准模态弹窗补充连贯的退出过渡，不改业务功能或扩大弹窗范围。

## 范围

- 包含：共享 DialogFrame、设置、添加账号、撰写邮件的现有关闭入口；遮罩同步淡出、
  减少动效偏好、重复关闭、动画中断/强制卸载、焦点恢复和请求取消回归。
- 不包含：Tooltip/下拉菜单/启动页/抽屉重设计、后端/依赖/凭据/数据格式变化。
- 保留 TASK-0041～0044 的全部未提交成果，不自动提交、推送、切换分支或创建工作树。

## 分析与取舍

- DialogFrame 当前只有入场 CSS 动画；设置直接调用原生 close，账号/撰写直接通知父组件卸载，
  因而只加退出 CSS 无法保留播放时间。
- 仅依赖 CSS display/overlay 离散过渡无法阻止 React 立即卸载；新增动效框架不符合最小闭环。
  拟使用共享退出状态与现有 CSS，等待外框/遮罩动画完成后 close/通知卸载，不增加依赖。
- 退出期间保留原生模态与焦点约束，阻止重复操作；不等待动画才取消账号请求。
  撰写发送期间原本不允许关闭，保持原策略；父组件强制卸载不人为延迟。
- 动效使用主题 Token、opacity/transform，兼顾快速入场即关闭、减少动效和无动画 API 降级。
  完成路径必须幂等且有兜底，不能因 animationend 丢失永久卡住。

## 验收标准

- [x] 设置的关闭、完成、Esc、有效遮罩点击均平滑退出，其他弹窗现有关闭入口同样生效。
- [x] 外框与遮罩同步退出，原生模态在动画结束前不提前移除；关闭回调只执行一次。
- [x] 关闭期间不能修改设置/重新提交；账号请求立即中止，后续批次不因延迟卸载继续启动。
- [x] 减少动效直接关闭；动画取消/缺失/强制卸载不挂起，不产生晚到关闭或误关新弹窗。

## 实现与验证

### 实现结果

- 新增共享 `useDialogExit`，三个业务组件统一接入；退出时保持原生模态，
  外框与遮罩使用 140ms 主题 Token 同步淡出，主体轻微下移，不动画布局尺寸或 blur。
- 外框关闭期间拦截点击、键盘和提交，完成路径幂等；等待外框/伪元素的实际动画，
  不等待业务子树的循环动画；动画取消、减少动效、无动画 API 与有界兜底均可结束。
- 入场中关闭先记录当前 opacity/transform/backdrop opacity，再接续退出，避免亮度/位置突跳。
  父组件强制卸载清理等待，旧完成信号不回调业务或关闭后续新弹窗。
- 账号关闭立即取消请求，退出期间晚到结果不启动第二项或通知成功；撰写发送中仍禁止关闭。
  未新增依赖、后端接口、数据迁移或凭据格式，TASK-0044 编辑布局及顺序保留。
- 工作拆为任务/失败测试、共享实现与接入、快速关闭边界修正、浏览器验证和文档步骤；
  每步不超过 10 文件 / 600 行，未改其他既有任务的业务需求。
