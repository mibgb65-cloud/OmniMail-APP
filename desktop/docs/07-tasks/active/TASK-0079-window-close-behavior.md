## 需求与范围
- 用户要求通用设置支持选择关闭窗口时直接退出或留在后台。
- 尚未设置时点击关闭必须询问，并允许选择是否将本次行为设为默认。
- 提供“每次询问”作为可恢复的未设定状态；记住选择复选框默认不勾选。
- 后台运行必须真正隐藏窗口且进程/同步继续，提供托盘重新打开与真正退出入口。
- 包含自绘关闭按钮、Alt+F4 等原生窗口关闭事件；取消或 Esc 保持程序与当前窗口。
- 不新增开机自启、不实现系统通知、不修改草稿/发送保护策略，不混入已有设置和撰写任务的其他改动。

## 分析与取舍
- 当前自绘关闭直接调用 Wails Window.Close；没有后台运行、托盘或关闭偏好。
- 只在 React 处理关闭会漏掉 Alt+F4，单纯隐藏窗口会导致无法恢复。
  采用 Go 原生 WindowClosing hook 拦截、服务层统一决策、前端模态选择及托盘恢复。
- 偏好保存在当前应用数据目录的独立小文件；无需数据库迁移，按限长/白名单读取、临时文件原子替换，
  非法/损坏回退询问并记录安全警告，不向 UI 泄漏绝对路径或内部错误。
- 未记住的单次选择不改偏好；记住时先成功持久化再隐藏/退出，失败保留弹窗让用户决定。
- 后台能力按平台适配明确暴露；本轮主要验收 Windows，未实测的平台不宣称原生行为通过。
- 保留工作树中 TASK-0073～0078 的全部未提交修改，不提交/推送、切分支或创建工作树。

## 本轮视觉反馈与修正计划（2026-11-01）
- 用户指出关闭确认窗过高且观感不佳；截图存在近半屏以上空白。
- 分析：原生 modal dialog 的上下 inset 配合 `height:auto` 会拉伸，
  不能把普通流式块的自适应高度写法直接用于顶层 dialog；还须避免与共用 frame 的尺寸规则同优先级竞争。
- 先增加可在实际 Chromium 验证的内容高度约束，再改为 `height:fit-content`、明确局部选择器优先级和溢出滚动。
- 视觉上移除无功能的大叉号装饰，改为真实右上角取消按钮；选项使用紧凑图标行、右侧自定义单选指示，
  缩短辅助文案，整理记住选择与操作栏。维持不默认选择、不默认记住、Esc/取消无副作用。
- 修正后截图核对亮暗色、窄视口与真实内容高度，并重跑必要测试和完整 verify。

## 最终实现
- `domain/window_close.go` 定义关闭行为白名单与偏好接口；`config/close_preferences.go` 对固定文件
  `window-close.json` 限长读取、普通文件检查、根目录约束以及随机排他临时文件+原子替换。
  缺少文件默认 ask，损坏回退询问并安全记录；没有数据库迁移。
- `service/window_close.go` 统一缓存偏好与待确认状态，使用互斥锁协调并发、单次/记住、取消和执行门禁。
  保存失败不执行隐藏或退出；不记住不写文件；恢复 ask 不执行关闭。
- Wails 装配注册 `WindowLifecycleBridge` 的 State/SetMode/Resolve/Cancel，原生 `WindowClosing` hook
  取消默认销毁并交由服务层决策。前端先订阅再读取快照，恢复 WebView 就绪前的关闭请求，
  忽略过期读取，不信任事件携带的行为数据。
- Windows/macOS 原生托盘使用现有品牌图标，点击或菜单打开窗口，明确 Quit 直接结束应用；
  第二实例也会 Show/Restore/Focus 现有窗口。Linux 暂不开放后台选项，不伪造恢复能力。
- 通用设置接入真实 Go 偏好，提供每次询问/退出应用/后台运行。统一关闭确认可覆盖设置等现有模态，
  不默认选项、不默认记住，取消/右上角/Esc 保留窗口；异步处理中阻止重复确认和取消交错。
- 根据用户反馈，弹窗改成明确局部尺寸优先级的 `height:fit-content`，去掉无功能的大叉号装饰；
  整理标题、短说明、图标选项、右侧选择指示、记住区和按钮区。超小窗口允许内部滚动，不留大片空白。
- 所有文案中英文齐备，沿用语义主题令牌，不新增依赖或系统自启动行为。页面规范和启动页已同步。
