# TASK-0007 统一设置语言下拉菜单样式

> 状态：待评审 | 负责人：@Codex | 创建：2026-10-25 | 最后更新：2026-10-25 | 优先级：P1
> 关联：用户反馈设置中的原生语言下拉菜单与应用风格不一致

## 需求与目标

在其他项目文件修改前建立本记录。将设置面板中的原生语言选择改为应用自绘菜单，
保留当前语言文字与箭头；顶部仍使用纯图标入口。两种入口共用语言状态和菜单行为。

## 范围

- 复用 LanguageMenu，增加文字选择器外观，保留当前语言选中标记。
- 处理原生 dialog 内的菜单层级、滚动裁切、可用空间和键盘焦点。
- 更新现有语言控件及依赖它的测试，保留存储异常和非法语言防护测试。
- 更新相关界面/多语言规范，运行完整 verify 并记录实际结果。

不增加依赖，不调整支持的语言、存储格式、品牌图标、邮件或通知能力，不提交或推送。

## 分析

- 当前顶部菜单已自绘，但设置仍使用 HTML select，选项列表由系统绘制，不能靠圆角 CSS 完整统一。
- 设置内容区有 overflow:auto，单纯把原生 select 换为绝对定位 div 可能被裁切。
- 计划使用手动原生 popover 提升菜单到顶层，仍保留自绘内容和既有轻量关闭逻辑；
  不支持该 API 的环境保留固定定位降级，当前 WebView2/Chromium 需实际验证。
- 语言状态继续通过 I18nProvider；不为美化菜单删除合理测试、伪装原生 select 或引入第二份偏好。
- 工作树已有大量其他任务改动，保持原样。

## 实现结果

已完成分析并开始实施：顶部保留 icon 模式，设置与带标签的选择器使用 select 外观模式；
共享同一菜单与 I18nProvider，不保留仅供测试的原生 select 分支。新增 ChevronDown 使用已安装
Lucide 1.61.0 的真实导出，不增加包或升级版本。

- LanguageSwitcher 已完全移除原生 select；两种外观均使用圆角卡片和选中勾选标记。
- 菜单优先使用手动原生 popover，视口固定定位、左右边缘约束及空间不足时向上展开；
  弹窗出现动效在菜单展开时停止，避免固定定位降级被祖先 transform 偏移。
- 更新上下文测试的实际用户操作，原有非法初始值、非法上下文值、存储失败和多 Provider 隔离防护仍保留；
  不存在原生下拉输入后，选项测试改为确认菜单只暴露支持的两种语言。
- 额外复现并修复小窗口 click/scrollIntoView 的晚到滚动事件误关菜单问题：
  只在锚点位置确实发生变化时随滚动收起，未移动锚点的滚动不误关。
- 所有生产语言选择器已统一为共享自绘菜单，不保留测试专用原生 select。
- 开发期变更自定义 Hook 签名时，旧热更新页面出现过 Hook 数量不一致；完成后已整页刷新开发窗口，
  并在全新浏览器上下文复核选择、Esc、顶层和运行时错误，未再出现错误，不把旧 HMR 状态当成验收页面。
