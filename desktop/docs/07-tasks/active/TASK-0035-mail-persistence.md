## 实现与验证

首版每个 `mail_message` 行表示一个服务器实例，不做跨文件夹内容合并；
账号、文件夹、UIDVALIDITY、UID 唯一识别，附件内容按哈希共享，MIME 正文按需获取。
普通同步游标与分段重对账游标分离，成功批次中同步删除已消失实例并提交进度。
缓存清理/容量管理后续独立实施，不能误删被其他邮件引用的共享文件。
