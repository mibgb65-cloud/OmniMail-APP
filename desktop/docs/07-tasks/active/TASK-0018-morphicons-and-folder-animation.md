# TASK-0018 统一 Morphicons 与分类气泡动效

> 状态：待评审 | 负责人：@Codex | 创建：2026-10-27 | 优先级：P1

## 需求与范围

- 全部现有功能图标使用 Morphicons 渲染，沿用 Lucide 图形数据；不更改应用品牌图像与原生图标。
- 分类切换时，气泡文字先淡出，气泡收缩后展开，新文字淡入；支持连续切换、中英文和减少动态效果。
- 仅修改前端，不接入真实邮件或 AI；用户已明确授权新增图标依赖。

## 分析与计划

- 目前功能图标统一通过 `UiIcon` 和 `lucide-react` 渲染，可在统一入口改用 `MorphIcon` 与对应 `lucide` 图标数据，保留名称、尺寸、颜色和装饰性语义。
- 安装固定版本 Morphicons 和与当前 Lucide 匹配的数据包，核对接口、许可、离线资源与依赖体积；移除不再使用的 React 图标依赖时保留适用许可。
- 气泡动效独立于图标变形，优先使用 CSS 和有限的文字切换计时；正确处理快速切换、减少动态效果和屏幕阅读器。
- 小步实施，保留用户工作区现有改动；执行针对性测试、开发预览及依赖变更要求的完整 verify。

## 验收标准

- [x] 现有功能图标全部经 Morphicons 渲染，保留一致尺寸、描边和无障碍语义；有状态图标切换可变形。
- [x] 分类气泡按文字淡出、收缩、展开、新文字淡入顺序切换，连续选择最终显示最新分类。
- [x] 系统减少动态效果时立即更新；不开启远程图标服务，不改变品牌图标。

## 实现与验证

- 移除 `lucide-react` 运行依赖，固定 `morphicons@2.0.2` 与 `lucide@1.61.0`，所有 `UiIcon` 统一使用 MorphIcon；状态变化时保留同一 SVG 实例。静态图标没有状态变化，不会自行播放动画。
- 分类气泡使用 CSS 过渡与延迟文字切换；最新选择立即反映于无障碍名称，连续切换会取消旧计时，减少动态效果时立即显示。
- 使用 `npm install --save-exact --ignore-scripts` 安装、`npm uninstall --ignore-scripts` 移除旧包；`npm audit --omit=dev` 报告 0 个已知漏洞。MIT 的 Morphicons 与 ISC/Feather MIT 的 Lucide 许可原文已复制进 public，并核对 dist 和安装包 SHA-256 一致；保留用户工作区已有的旧许可文件。
- 完整门禁 `go -C desktop tool wails3 task verify` 通过：Go 格式、vet、测试、前端格式、lint、类型检查、21 个文件 208 项测试及 Windows 生产构建；产物为 `desktop/.task/verify-bin/OmniMail.exe`，不覆盖开发可执行文件。追加测试后的首轮验证因测试文件格式失败，格式化后重跑通过。
- 构建产物主 JS 299,107 字节、region 按需块 12,655 字节、CSS 31,129 字节；尚无同一代码状态下的替换前构建基线，不能据此计算可靠净增量。整个 dist 被 Go embed，按需块包含在产物中。
- Chrome 1120×700 开发预览确认主题和 AI 按钮保留同一 SVG，状态改变时有中间形态；气泡顺序及快速连续选择正常，模拟减少动态效果时立即切换，页面无溢出、无外部图标请求。浏览器因不具备 Wails 桥接产生已有的取消请求提示，不能据此证明桌面桥接行为。
