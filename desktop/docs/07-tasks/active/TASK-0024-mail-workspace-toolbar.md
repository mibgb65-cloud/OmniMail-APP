## 需求与范围

- 邮件区域分为上下两部分：上方通栏工具条，左侧搜索、同步，右侧归档、删除、标为已读/未读、全部已读、邮件数量、上一封和下一封。
- 下方保留左侧邮件列表、右侧内容区；不改变右侧 AI 分析区域。
- 仅实现前端 UI；未接入的操作禁用、邮件数量显示未知，不伪造邮件或同步结果。

## 分析与计划

- 当前邮件面板直接横排两列，分别有独立标题；增加独立 MailToolbar 组件并把两列放入下方填充区。
- 使用现有 Morphicons 统一入口补齐实际需要的图标，中英文同步；搜索框允许输入预览但不发送请求，限制输入长度。
- 工具条在宽窗口保持单行，最小桌面窗口可内部换行以避免溢出，首页继续无横纵滚动。
- 按步骤实现组件/布局/文案、测试和文档，各步骤不超过仓库规模限制。使用热更新及轻量验证，不新增依赖、不修改后端、不重新打包。
