## 需求与范围

- 左侧六个邮件分类未选中时显示 outline，选中时显示 fill，双向切换由 Morphicons 变形。
- 保留共享选中滑块、图标语义、亮暗主题和减少动态效果；仅修改前端。

## 分析与计划

- 现有 `selected` 只在同形紧凑与标准形态间变化，并非实心；Morphicons 负责变形，但需要提供真实实心图形数据。
- 描边沿用当前 Lucide；实心静态按需采用 Heroicons v2.2.0 的六个 24×24 SVG（MIT），本地保存并解析为 Morphicons 输入，不添加 npm 依赖、不使用远程运行服务。
- 核对 SVG 只包含静态路径、视框和填充属性，保留许可与来源；不要简单给描边图标填色而遮盖内部细节。
- 更新统一图标入口和关键测试；检查双向中间形态、连续切换、减少动态效果及离线资源，按风险验证，不重复完整打包。
- 保留既有工作区改动，不清理其他任务内容。
