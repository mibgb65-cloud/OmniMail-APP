# TASK-0019 点击位置圆形扩散主题切换

> 状态：待评审 | 负责人：@Codex | 创建：2026-10-27 | 优先级：P1

## 需求与范围

- 为右上角主题按钮加入基于点击坐标的 Circular Reveal，使用原生 View Transitions API 和 clip-path，时长 700ms。
- 封装可复用 Hook，在快照回调内同步提交现有 React 主题状态；保留主题持久化、Morphicons 及无障碍行为。
- 不支持 API、减少动态效果或快照/动画无法执行时直接切换主题；设置页开关继续复用原有主题状态，不擅自扩展动画范围。

## 分析与计划

- 现有 `useTheme` 通过 layout effect 应用 data-theme，可用 React `flushSync` 在快照前同步完成更新。
- 点击采用 clientX/clientY；键盘触发采用按钮中心，坐标按视口边界校验。半径按用户公式计算，动画期间防止重复启动，卸载时清理。
- 禁用本次 root 新旧快照的默认混合/淡入淡出，让新主题置于上层圆形展开。
- 不增加依赖、不改后端，保留既有工作区改动；执行针对性测试和浏览器预览，不重复完整打包。
