# TASK-0020 侧栏共享选中滑块

> 状态：待评审 | 负责人：@Codex | 创建：2026-10-27 | 优先级：P1

## 需求与范围

- 左侧邮件导航的选中背景使用共享圆角滑块，在不同菜单项之间平滑位移及高度过渡。
- 使用原生 React 与 CSS，不增加 framer-motion；保留分类选择、Morphicons、键盘及亮暗主题。

## 分析与计划

- 当前背景由每个按钮独立设置，切换时直接消失/出现；改为导航容器内一个绝对定位且不可交互的共享背景。
- 通过按钮 ref 测量相对位置和高度，使用 400ms 位移/高度过渡，缓动 `cubic-bezier(0.25, 1, 0.5, 1)`。
- 初次定位不动画；布局、语言及窗口变化后重新校准，清理观察器和帧回调；减少动态效果时立即定位。
- 图标和文字位于滑块上层，按钮背景透明；滑块颜色使用既有主题令牌。
- 保留既有工作区改动；执行针对性测试和浏览器预览，不重复完整打包。

## 验收标准

- [x] 只有一个共享滑块，切换与快速连续选择时从当前位置平滑移动到最终选中项。
- [x] 滑块不遮挡文字、图标或焦点；语言、窗口变化及减少动态效果均正确。
- [x] 中英文、亮暗主题及原有选择行为有实际验证。

## 实现与验证

- 在导航内增加唯一共享背景，通过按钮 ref 测量相对位置及行高；CSS 使用 400ms 位移和高度过渡，按钮透明、文字和图标在上层，颜色复用亮暗令牌。
- 初次定位后才开启动画；ResizeObserver、窗口 resize 与语言变化会重新校准，卸载时清理观察器、监听和帧回调。
- `npm run test -- src/app/WorkspaceSidebar.test.tsx src/app/App.test.tsx`：2 个文件、24 项通过；类型检查与 lint 通过，本次三个前端文件已格式化。

- Chrome 英文深色、减少动态效果预览使用 Enter 选择后保持焦点；调整为 860×600 后滑块仍与目标对齐，背景为深色令牌、过渡时长为 0，无页面溢出。
