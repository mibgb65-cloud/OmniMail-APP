- 使用只读文件统计，不查询邮件内容、不修改数据库、不扫描用户任意路径；符号链接不跟随。

- `SettingsNavigation` 增至八个分类；`SettingsSections` 提供邮箱入口和能力状态页，邮箱数量来自当前邮件控制器。
