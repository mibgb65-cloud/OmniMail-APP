# TASK-0013 固定首页工作区

> 状态：待评审 | 负责人：@Codex | 创建：2026-10-27 | 优先级：P1

## 需求与范围

- 首页右侧邮件和 AI 工作区适配窗口高度，去除横向与纵向滚动。
- 保留 AI 面板收起展开；设置弹窗内容不属于首页，继续允许内部滚动。
- 仅调整前端布局，不实现邮件或 AI 功能；保留既有工作区改动。

## 分析与计划

- 当前首页容器开启滚动，而工作区使用视口最小高度叠加内边距，导致纵向溢出。
- 将首页内容限制在可用视口内，让工作区填充剩余高度；检查不同窗口尺寸、收起状态和设置弹窗。
- 仅进行轻量测试和开发预览，不执行完整打包。

## 验收标准

- [x] 桌面支持尺寸下首页没有横向、纵向滚动，邮件与 AI 面板位于窗口范围内。
- [x] AI 收起展开与设置弹窗仍可用；设置长内容可滚动。
- [x] 记录实际验证和限制。

## 实现与验证

- 首页容器禁止滚动，邮件与 AI 工作区填充可用高度；设置弹窗不受影响。
- `npm run test -- src/app/MailWorkspace.test.tsx src/app/App.test.tsx`：2 个文件、15 项测试通过；两份 CSS 的 `npx prettier --check` 通过。
- Chrome 开发预览在 860×600、1120×700、1750×950 下验证 AI 展开/收起时页面无横纵溢出，滚轮后页面偏移不变且面板位于视口内；860×600 设置关于页可独立滚动。
- 未做完整打包或其他平台桌面实测。窗口小于项目的 860×600 最小尺寸时，现有窄屏布局可能裁切，不属于本次桌面支持范围；未来真实邮件内容可能需要重新设计区域内阅读方式。
