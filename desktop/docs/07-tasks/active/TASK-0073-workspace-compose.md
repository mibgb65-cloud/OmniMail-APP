## 设计与安全边界
- 撰写状态提升到 App 会话层，临时查看邮件不销毁编辑数据、不取消已发起发送；
  浏览账号变化不隐式更换发件人。
- 从可用的当前账号进入则预选该账号；全部邮箱且仅一个账号时可预选；
  多账号或原选中账号不可用时明确选择，不静默使用列表第一项。
- 右侧提供紧凑、限高、键盘可操作的发件人选择；完整邮箱可辨认；
  发送时重新确认账号仍可用，不将 UI 显示和后台 accountId 搞成两个身份。
- 返回与放弃分离；放弃未发送内容经短确认。明确提示仅本次会话保留，不自动保存草稿。
- 发送保留后端输入校验，前端同步锁防重复提交；发送中禁止修改快照/放弃，
  可以浏览再返回。空主题/正文需要当次确认；成功仅说服务器接受，不宣称已送达。
- SEND_UNCERTAIN 保留内容并禁止直接重发，提示核对已发送；
  不把网络取消当成邮件撤回，测试只使用 mock，不发送用户真实邮件。
- 撰写时隐藏 AI 分析区域以释放空间，返回后恢复原有展开偏好；阅读区保留挂载/滚动状态。
