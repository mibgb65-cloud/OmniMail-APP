## 分析与决策
- 复用 WorkspaceSidebar 的标题工具按钮和 MailboxAccounts 的真实账号行/状态，
  不维护第二套邮箱选择业务；分组仅按真实 providerCode，不猜测邮箱域名/服务器。
- 网易 163/126 以同一网易品牌分组（沿用添加向导），其他服务商按真实代码；
  未知服务商显示安全文本/通用图标，custom 不按域名猜成内置品牌。
- 分组顺序遵循账号首次出现顺序，组内保留原账号顺序，显示邮箱个数而不是邮件数量。
- 切换模式、进入组、返回组不改变 selectedAccount；当前账号所在组提供提示。
  “全部邮箱”始终为全局选择，内层点击时同时回到服务商入口，避免误解为仅该组全部。
- 默认平铺，模式仅本次会话保留，不新增持久偏好或数据库迁移。
