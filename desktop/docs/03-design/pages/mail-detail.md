# 邮件详情页

> 状态：草稿（含当前实现说明） | 负责人：@design-lead | 最后更新：2026-10-31
> 相关：[FEAT-0007 安全渲染](../../01-product/features/FEAT-0007-safe-html-render.md) · [主界面](inbox.md)

## 目标与入口

### 当前实现（TASK-0048）

- 右侧阅读器展示经 Go 清洗后的 HTML、表格与内嵌 PNG/JPEG/GIF/WebP，
  纯文本邮件安全回退。原始 HTML 保留在 Go/SQLite 内部，不直接返回前端。
- TASK-0052：邮件头独立排版，主题单独成层，左侧显示发件人/收件人，右侧显示语义化收件时间；
  窄窗口时间换为独立右对齐行，长邮箱最多两行并可通过复制按钮的统一提示查看完整地址。
  两类邮箱分别支持复制和成功/失败反馈，支持键盘，多收件人保留顺序。
  桌面桥接检查系统剪贴板真实 bool 回执，不将失败误报为成功；浏览器采用标准写入权限。
- 阅读区移除数据库持久化/脚本安全的常驻技术说明及无用翻译键，
  不改变真实存储/安全隔离，也不移除旧版正文恢复、图片隐私或错误等必要提示。
- TASK-0054：主题右侧提供与列表共享状态/请求的星标按钮，读取临时期望值和最新列表状态，
  不直接依赖可能滞后的正文详情；保存中防重复、失败回滚，离场/准备页禁用。
  收发件人行间距由 8px 收为 2px，标题与元信息/分隔线的留白收紧，复制点击区仍为 28px。
- iframe 固定 `sandbox="allow-same-origin"`、`referrerpolicy="no-referrer"` 与严格 CSP，
  无邮件脚本、表单、嵌套 frame、外部字体或样式表。邮件底板保持浅色以避免强制反色破坏原有配色，
  阅读器外围和设置随应用浅深色主题变化。
- “通用设置 → 邮件图片”：不显示、仅内嵌（默认）、全部；即时生效并保存于当前 WebView 来源的
  `localStorage`。选择全部会允许远程图片暴露阅读行为，界面在选项前披露风险；
  存储失败时明确提示仅在本会话生效。
- 被拦截时可点击“仅本封显示图片”；切换邮件或改变全局偏好后临时许可重置。
  远程图片交由 WebView 加载，不经 Go 代理；因此远程服务可用性、响应大小由浏览器处理，
  不等于承诺任意图片均可显示。
- 外部链接经父页面协议校验后先弹出安全确认框，展示实际域名和完整 URL，明确说明应用未验证其安全性，
  默认聚焦取消，仅用户当次确认后交系统浏览器。取消、Esc 或切换邮件不打开链接，不记忆永久信任。
- 链接不使用原生黑色 `title`，改为主应用统一 Tooltip：上方域名、下方可换行 URL，
  随浅深色主题变化；支持受控 iframe 的鼠标/键盘及跨文档定位，滚动和卸载会关闭。
- 旧版正文无法凭本地纯文本恢复排版，提供“重新获取完整内容”；离线/断开或服务器失败会明确报错，
  保留旧正文与附件。TASK-0058 增加后台有界补齐缺失/旧版正文，当前版正文不因状态轮询而反复下载。
  文字和 HTML 持久写入数据库，图片/附件保留文件引用；缺图降级不应导致文字不可读。
  尚未补齐时不宣称离线正文已完整，详情见
  [TASK-0058](../../07-tasks/archive/2026/10/TASK-0058-offline-mail-persistence.md)。
- TASK-0050 将正文读取从后台同步互斥中拆出，使用独立有界连接；同步轮询和星标完成只刷新列表，
  不取消在途正文。切换邮件或用户主动重试仍可取消旧读取，服务端网络耗时不被隐藏为成功。
- 缺失/不支持/超预算的内嵌图片显示降级提示，附件另存保持原流程。
- TASK-0051：网络读取及隔离正文准备时显示左至右流光骨架；允许的图片加载/解码、布局测量完成后
  经两帧布局确认淡入，减少动态偏好时不播放流光或淡入。图片迟缓 12 秒后可主动选择先阅读，
  不自动扩大图片许可，也不把未完成图片假装成已加载。
- 邮件内部不再出现横竖滚动条，由外层阅读区统一滚动；固定宽布局优先响应式收敛，
  剩余不可收敛宽度等比缩放，正常长正文完整扩展 iframe 高度。
  PageUp/PageDown、方向键、Home/End 等阅读滚动转交外层；Tab/Enter/带修饰键快捷键保留。
- 不可信布局宽度超过 12000px 或适应后高度超过 32000px 时明确改为所提供的完整纯文本，
  不以隐藏 overflow 静默截断；图片仍按既有安全预算和许可处理。
  视口单位内联尺寸会被剥离，避免 iframe 高度反向驱动 `vh` 布局形成自增循环。
- TASK-0053（2026-10-31 续作）：切换立即释放上一封邮件，仅准备当前目标，
  无论是否已缓存，都统一显示实色背景的左至右流光骨架，不再保留旧页、半透明覆盖或交叉位移动画。
  280ms 短窗口与网络/图片准备并行计时；慢请求完成后不额外等待，减少动态时无强制视觉等待。
- 准备中的唯一新页隐藏且 inert；就绪且短窗口结束后进入统一的自上而下分段入场，
  不叠加旧的整页交叉/正文整体淡入动画。
  快切、A→B→A、账号/分类切换释放旧回调，切换重置外层阅读位置；错误停止骨架并提供安全重试，
  慢图先读入口位于骨架之前，不藏在不可操作的准备页中。
- 满高骨架沿阅读器 flex 高度链填满可用内容区；高窗口补充下半区占位段落，
  小窗口自动收敛，不为加载态产生额外滚动条。仍由单一外层阅读区承接长邮件滚动。
- 标题、邮件信息、正文块和附件按首屏可视位置由上到下错峰入场；
  HTML 单列布局表格保留原 DOM 并穿透外壳，多列表格以行分组，纯文本按有限自然段展示。
  使用受控 Web Animations API，只修改 opacity/transform，每段 320ms、最大延迟 420ms，
  首屏最多 18 块，总时长不超过约 740ms，不延长网络请求或等待所有动画后才能操作。
  快切/卸载取消旧动画，星标更新不重播；减少动态、键盘聚焦或无动画能力时直接展示最终内容。
- HTML 正文颜色跟随应用深浅主题，深色覆盖正文背景、文字、链接与边框，不反转图片；
  阅读区不再显示逐封配色按钮，统一由“设置 → 通用设置 → 语言与外观”中的
  “邮件正文跟随暗色模式”开关控制，默认开启；关闭后保留 HTML 邮件原始配色。
  偏好在本机保存、即时作用于当前和后续邮件，不改变应用主题、原始 HTML、图片权限或沙箱/CSP。
  切换无需重载 iframe、重新请求图片或重播入场动画；存储受限时只在本会话生效并提示未保存。
- 正文 iframe 不额外绘制应用外框或圆角，避免邮件呈现为嵌套卡片；
  保留原有内边距、底色、完整高度，以及邮件自身的表格边线与分隔线。
- 工具栏已读/未读、当前筛选结果的已加载未读批量标记、归档及移入垃圾箱接入真实服务端回写。
  归档/删除要求唯一目标文件夹和 MOVE/UIDPLUS 能力，不永久删除、不降级到 EXPUNGE；
  成功后持久化新 UID 并保留原 ID/正文/附件。缺失能力及移动结果不确定均明确提示，不自动重试。
- 自动已读：当前邮件正文准备成功、骨架结束并实际展示后，使用现有
  `SetRead → IMAP UID STORE +FLAGS \Seen` 回写对应服务商，确认后才更新本地状态、列表和未读计数。
  例如 QQ 等服务商网页刷新后应能读取相同已读状态；真实服务商验收以任务记录为准。
  选择列表、快切未展示、失败、后台/开屏/弹窗遮挡和断连账号均不算成功阅读，不因下载正文自动标记。
- 每次打开只通知一次，手动标未读优先；等待其他操作时仅保留最新当前邮件通知，
  未发出的旧选择/旧账号通知取消，已发送并确认的远端已读不因后来切走而撤销。
  失败时正文继续可读，阅读器提示失败且可手动重试，不自动循环请求。
  TASK-0057 调整未读筛选：自动/手动已读仍真实回写并更新行状态和未读计数，
  但本轮未读筛选中的邮件不会因变为已读而移出，连续阅读多封仍保留选中位置与前后导航。
  只有主动同步或切换搜索/筛选条件才重新计算未读成员，账号/分类切换使用新的视图范围；
  仅切换时间排序不重算成员。后台轮询与正文缓存重验不重置本轮筛选。
  用户加载下一页可扩展新的未读成员，主动同步完成后继续保持本轮列表稳定；
  明确归档/删除或真实移出的邮件仍移除，不保留幽灵条目。
  未实现历史设计中的 3 秒延迟或离线回写队列。详见
  [TASK-0057](../../07-tasks/archive/2026/10/TASK-0057-stable-unread-filter.md)。
- 验证结果与未验证项以 [TASK-0048](../../07-tasks/archive/2026/10/TASK-0048-rich-mail-reader.md) 为准；
  后续交互修正见 [TASK-0049](../../07-tasks/archive/2026/10/TASK-0049-mail-reader-interactions.md)；
  加载与滚动见 [TASK-0051](../../07-tasks/archive/2026/10/TASK-0051-reader-loading-skeleton.md)；
  连续切换与抗闪烁见 [TASK-0053](../../07-tasks/archive/2026/10/TASK-0053-reader-switch-transition.md)；
  以下布局和操作仍包含未落地的历史设计目标。

主界面右栏（宽屏分栏）或覆盖层（< 960px）。目标：快速读懂内容、安全地打开外部资源、
一键回复或归档。

## 布局

```
┌───────────────────────────────────────────────────────────────┐
│ 主题标题（1-2 行，可选中复制）                         ⋮  ⋯   │ 工具条 40px
│ 发件人 显示名 <ADDR>   收件人▾   14:32   账号标签             │ 元信息 48px
├───────────────────────────────────────────────────────────────┤
│ ⚠ 为保护隐私，已阻止远程内容。 [显示图片]   [仅在浏览器中打开] │ 安全条 36px
├───────────────────────────────────────────────────────────────┤
│                                                               │
│   正文（沙箱 iframe，主题同步）                                │ 滚动区
│                                                               │
├───────────────────────────────────────────────────────────────┤
│ 附件： report.pdf 1.2MB  [下载]    img.png 84KB               │ 附件区（有则显示）
├───────────────────────────────────────────────────────────────┤
│ [↩ 回复] [↩↩ 全部回复] [↪ 转发]                    [归档] [删] │ 操作条 48px 固定底部
└───────────────────────────────────────────────────────────────┘
```

## 区域与元素

| 区域 | 规格 |
| --- | --- |
| 主题 | `--text-lg`，500 字重，最多 2 行，
超过省略（hover 显示 tooltip 全文） |
| 发件人 | 显示名 + `<addr>`，点击展开详情（发件时间、Reply-To） |
| 收件人 | 默认收起为"收件人 ▾"，展开显示 To/Cc/Bcc 全部地址 |
| 账号标签 | 小号徽标，点击切到该账号视图 |
| 安全条 | 仅在有远程资源被阻止时出现，提供两个动作 |
| 正文 | iframe，高度自适应内容（最小 240px），最大高度 = 容器高（内部滚动） |
| 附件 | 文件名、大小、类型图标、下载/预览按钮；图片可内联预览 |
| 操作条 | 固定在详情底部，主操作左对齐，破坏性操作右对齐并用次要样式 |

## 交互与状态

| 场景 | 行为 |
| --- | --- |
| 加载中 | 正文区骨架（6 行灰条），工具条立即可用 |
| 纯文本邮件 | 用 `--font-mono` 或 sans 渲染，保留换行（`white-space: pre-wrap`），链接自动识别 |
| 远程资源被阻止 | 顶部安全条；点击"显示图片"后不再出现（按发件域记忆） |
| 点击链接 | 交系统浏览器打开，详情不跳转；`javascript:` 等协议静默丢弃 |
| 会话聚合 | 顶部显示"共 N 封"，可折叠前 N-1 封（默认折叠，只展开最新） |
| 已读 | 打开即标已读；若用户 3 秒内关闭，保持未读（可设置） |
| 删除 | 立即从列表移除，Toast 提供"撤销"（8 秒） |
| 附件超限预览 | 提示"文件过大，请下载后查看" |

## 键盘操作

| 键 | 动作 |
| --- | --- |
| `r` | 回复 |
| `a` | 全部回复 |
| `f` | 转发 |
| `e` | 归档 |
| `Del` | 删除 |
| `o` | 在浏览器中打开 |
| `Esc` | 关闭详情（覆盖层模式） |
| `Ctrl/Cmd+↑/↓` | 上/下一封 |

## 数据依赖

`Mail.GetBody`（含正文、附件列表、内嵌 cid 映射）；订阅 `mail:updated`（若该邮件状态变化需同步 UI）。

## 验收要点

- [ ] 恶意 HTML 样例（脚本、表单、跟踪像素）不执行、不发起请求（见 [TC](../../05-testing/test-cases)）。
- [ ] 正文 iframe 内主题切换即时生效，无需重新打开邮件。
- [ ] 长邮件（5000 字 + 10 张图）打开耗时 < 400ms。
- [ ] 附件下载有进度与完成提示；失败可重试。
- [ ] 会话折叠区可展开/收起，状态在切换邮件后重置。
- [ ] 所有按钮有 `aria-label`，操作条键盘可达。
