## 通用布局约束

邮件标题与正文翻译见 [邮件翻译](mail-translation.md)
（TASK-0085，首期手动翻译已接入；与界面国际化是不同能力）。

通用 AI 配置、单封分析和回复建议见 [邮件 AI 助手](mail-ai.md)
（TASK-0090～0094，主动授权与纯文本结果；不自动分析或发送邮件）。

待办、跨邮件需求关联和独立授权的每日调度见 [待办与每日邮件需求](requirements-tasks.md)
（TASK-0097～0100，实现待评审；仅运行/托盘执行，错过后启动补跑）。

```
┌──────────┬────────────────┬─────────────────────────────┐
│ Sidebar  │  MailList      │  Detail                     │
│ 240px    │  320-400px     │  剩余                        │
│ 可折叠56 │  可拖拽        │  <960px 时改为覆盖式        │
└──────────┴────────────────┴─────────────────────────────┘
```

- 断点：`< 960px` 两栏（侧栏可收起，详情覆盖）；`>= 1280px` 三栏舒适；`>= 1600px` 列表默认 400px。
- 各栏独立滚动，头部工具栏固定。
- 面板宽度可拖拽并持久化（`uiStore.panelWidths`）。
