# 启动页与初始化工作台

> 状态：已生效 | 最后更新：2026-10-28
> 范围：当前工程初始化界面；不代表邮箱、邮件或数据库能力已实现。

## 视觉方向

- 参考用户提供的开屏与工作台图片：白底品牌过渡、浅灰画布、圆角侧栏、轻边框卡片。
- 应用标识统一采用原始完整蓝色渐变信封；按用户澄清，图标外部透明，不加白色底座、白边或额外留白框。侧栏、开屏、工作台、设置弹窗和 favicon 使用同一 SVG，不再混用简化版，不随亮暗主题重新着色。导航与窗口控制等功能图标不替换为应用标识。
- 本页覆盖设计系统草稿中的蓝色主操作与紧凑布局，仅适用于初始化工作台；未来邮件列表仍保留高密度设计目标。
- 继续使用 CSS Modules、语义令牌及本地系统字体；经用户确认，功能图标由
  [Morphicons / UiIcon](../components/icons.md)渲染并静态按需引用描边及实心图形数据。

## 开屏行为

- React 挂载时播放一次，后台同时请求真实 Go 版本信息。
- 正常连接后展示至少 1.1 秒，再用 240 毫秒淡出；细线是无百分比的品牌动效，不代表真实初始化进度。
- 服务未响应时最多等待 3.5 秒，随后淡出，让用户在工作台查看连接状态及重试。
- 不显示“跳过动画”按钮；按 Esc 可提前退出，系统启用减少动态效果时不播放或强制等待。
- 退出由计时器控制，不依赖动画结束事件；组件卸载会清理计时器和监听。
- 开屏期间工作台不可聚焦，退出后焦点移到工作区；重播不重建工作台、不重新请求 Go。

## 验证与回滚

- 在 `desktop/frontend/` 执行 `npm run check` 和 `npm run build`，检查正常退出、连接未响应、跳过、减少动态效果、卸载清理与中英文一致性。
- 桌面验证使用 Wails 开发模式；浏览器预览不能证明 React 与 Go 已连接。
- 浏览器自动化中的正常连接布局使用显式测试数据；真实连接必须另在桌面窗口确认。窗口宽度检查覆盖 390、860、1120、1760 像素。
- 开发中新增语言键后，既有 i18next 实例可能保留热更新前的资源；完整重载窗口后再验收新增文案与首次启动效果。
- 自绘标题栏按用户于 2026-10-25 的后续要求实施，替代初版保留原生标题栏的约定，最新实现见下节。
- 动画入口与工作台样式独立；若需取消，移除 App 中开屏入口并恢复本次工作台样式，不改变绑定协议或用户数据。

## 自绘控制栏与主题

- 主窗口启动默认尺寸为 1750×950，最小尺寸仍为 860×600；保留手动缩放、最大化和还原能力。
- 主窗口启用 Wails `Frameless`，不再绘制原生标题栏。侧栏从窗口顶部开始，占据完整高度；操作栏仅固定在右侧工作区顶部，语言、主题、最小化、最大化/还原、关闭位于同一操作区。
- 工作台顶部语言入口为 34px 高的横向展开胶囊：收起显示文/A 翻译图标与当前语言简写（简中 / EN），hover 或 focus-within 时显示全部语言；选中项使用主要文字、500 字重与展开态内嵌高亮，其他项使用次要文字及悬停反馈。颜色复用现有主题 Token，过渡为 0.28s、`cubic-bezier(0.16, 1, 0.3, 1)`，遵守减少动态效果偏好。Tab 正常进出，左右方向键/Home/End 移动焦点，Enter/Space/点击立即切换并保存；区域禁止拖动窗口，不创建下拉菜单或 Popover。
- 语言高亮使用单个共享胶囊，在两个 44px 等宽选项之间滑动；切换位移为 460ms、`cubic-bezier(0.34, 1.56, 0.64, 1)`，呈现约 4px 的轻微越界回弹。连续切换从当前位置接续，不排队或延迟切换语言；收起隐藏高亮，减少动态效果时直接到达目标。
- 语言按钮显式重置全局主按钮的 hover 背景：选中项自身始终透明，由共享滑块提供高亮，避免浅色模式出现深底深字；未选中项单独使用浅层 hover 背景，不修改全局按钮或主题配色。
- 按用户后续要求，操作栏不再重复展示图标、OmniMail 名称及“开发预览”；左上角侧栏只显示图标与 OmniMail 名称，名称字号为 20px，不显示“桌面端 / DESKTOP”副标题。此处只调整应用内操作栏，不影响 Windows 任务栏图标。
- 工作空间导航依次展示全部收件箱、星标邮件、已发送邮件、草稿箱、归档邮件、已删除邮件；分类按钮采用约 36px 的紧凑高度，按钮之间间隔 4px，可切换前端选中状态，图标通过 Morphicons 在未选中描边与选中实心之间变形。顶部气泡与左侧卡片顶部对齐，上下留白各为 12px；切换时旧文字淡出、气泡收缩至“……”，省略号完整显示约 400ms 后淡出，再展开并淡入新标题，总时长约 1.6 秒。减少动态效果时立即切换，默认选择全部收件箱。当前仅为 UI 预览，未接入邮件数据或真实邮件页面。
- 分类选中背景使用一个共享圆角滑块，位移和高度以 400ms、`cubic-bezier(0.25, 1, 0.5, 1)` 平滑过渡。按钮本身背景透明，文字和图标位于滑块上层；首次定位无动画，窗口、语言或行高变化后重新测量，减少动态效果时立即定位。
- 分类按钮的文字禁止拖选，不出现蓝色文本选区；不阻止按钮正常获取焦点、键盘激活或切换分类，页面正文仍可选取。
- 分类气泡后依次显示同步时间、未读邮件两个只读状态气泡；邮箱未接入时显示“未同步”和“—”，不把未知数量写成 0，也不伪造同步时间。状态随中英文与主题更新，开屏期间隐藏。
- 工作区展示邮件列表、邮件查看和右侧 AI 分析占位区；AI 面板可收起和展开，宽度平滑过渡并遵守减少动态效果设置，窄浏览器视口下自动换行。邮件与 AI 均未接入，空态不代表实际数据或分析结果。原工程初始化、连接诊断与开屏重播移至“设置 → 关于”，首页不再显示开发状态。
- 邮件面板采用上下结构：上方工具条跨越两列，左侧为搜索框、同步入口，右侧依次为归档、删除、标为已读/未读、全部已读、未知邮件数量及上一封/下一封；下方为邮件列表和内容两列。搜索仅允许最多 200 字的输入预览，其他邮件操作禁用；窄窗口工具条可换行，首页不新增滚动。
- 品牌名称下方、工作空间导航上方提供带铅笔图标的“写邮件”按钮，高度为 40px。当前邮箱接入、撰写及发送模块尚未实现，因此禁用并显示“待开发”，悬停提供原因说明；本次只增加入口，不伪造发送或草稿能力。
- 侧栏底部不再展示“本地优先”等三行说明，原位置改为唯一的设置按钮，上方导航不重复保留设置项。按钮已启用，打开基础偏好悬浮窗；窄屏预览也保留此入口。
- 设置入口通过自动上边距保持底部对齐，侧栏底部内边距为 8px，不绘制按钮上方的分隔线；顶部与左右内边距保持不变。
- 同一底部行的右侧放置纯铃铛消息按钮；两按钮高度统一为 40px，图标和文字垂直居中，设置按钮不额外叠加上下内边距。左侧设置按钮可伸缩，保持整行靠底部。点击铃铛向上展开消息卡片，窄屏预览则向下展开以避免顶部裁切。
- 操作栏空白区域使用 Wails `--wails-draggable: drag`，双击切换最大化。右侧操作区明确设为 `no-drag`，避免操作按钮时误拖窗口。
- 窗口控制统一通过 `lib/bridge/window.ts` 调用当前固定版本的 Wails Window API。只接受白名单操作，查询校验布尔结果，调用最多等待 3 秒，异常映射为安全的中英文提示。
- 监听主窗口最大化、取消最大化及还原事件，更新按钮图标与标签；卸载清理订阅，忽略过期查询。浏览器预览禁用原生窗口按钮，但语言和主题操作仍可使用。
- 固定版本 beta.34 的原生窗口事件只分发到当前 WebView，且 `sender` 为空；不能用 `sender === 'main'` 排除这些事件。带有明确其他窗口来源的自定义事件仍忽略。
- 操作栏位于开屏与工作台之上；开屏期间只显示最小化、最大化和关闭按钮，操作栏全宽且背景与开屏一致，浅色模式为纯白色。开屏结束后恢复语言和主题入口；开屏覆盖整个窗口，避免侧栏上移后露出未就绪内容。首页工作区适配窗口可用高度，收紧上下外侧留白，不提供横向或纵向页面滚动；设置弹窗的长内容仍可独立滚动。
- 宽度不超过 680px 的浏览器预览中，操作栏改为全宽，侧栏排列在其下方，避免与右侧按钮重叠；桌面窗口最小宽度仍为 860px。
- 主题初次跟随系统；未手动选择时响应系统主题变化。手动选择 `light` 或 `dark` 后写入 `omnimail.theme`，优先于系统；非法存储值被忽略，存储失败仍保留会话内选择。
- 语义令牌覆盖工作台、开屏、选择框、按钮及状态颜色，亮暗切换不重建工作台或重新请求 Go。主题在 React 首次绘制前应用；原生 WebView 加载前的宿主背景仍为浅色。
- 右上角主题按钮使用原生 View Transitions 从点击位置圆形扩散，时长 700ms，缓动为 `cubic-bezier(0.4, 0, 0.2, 1)`；键盘激活使用按钮中心。新主题快照在上层展开，禁用默认淡入淡出和混合；过渡中不重复启动。缺少 API、动画能力不足或系统减少动态效果时直接切换，设置页开关不额外触发全屏动效。
- 圆形动效不保留结束后的 WAAPI 填充效果；同时等待扩散动画和原生过渡结束，再释放动画与切换锁，防止连续切换复用上一轮残留效果。
- Windows 桌面窗口是本次验证目标；macOS/Linux 行为、Windows 最大化按钮悬停的系统 Snap Layout 菜单未承诺实现或验证。

## 设置悬浮窗

- 使用原生 `<dialog>.showModal()`，在窗口内居中显示圆角面板；`::backdrop` 叠加半透明遮罩与 10px 背景模糊，覆盖工作台、侧栏和顶部操作栏。
- 按用户参考图改为约 900×580 的双栏布局：左侧“设置与关于”分类列，右侧固定标题、可独立滚动的内容区和底部操作区。当前提供“通用设置”和“关于”，不照搬尚未实现的开机启动、托盘、数据存储或更新检查选项。
- 左侧采用垂直 tablist，点击或使用上下箭头、Home/End 切换右侧 tabpanel；Tab 首尾循环跟随当前分类，切换分类不关闭弹窗或重建工作台。
- 原生模态层约束 Tab 焦点并阻止点击背后控件；关闭后恢复到触发设置的按钮。关闭按钮、“完成”、Esc 和真正的遮罩点击均可关闭；点击面板留白、从面板内拖到遮罩不会误关闭。
- 通用设置提供已实现的界面语言和亮暗主题。语言复用 I18nProvider，主题由 App 统一持有，顶部与弹窗同步；修改立即生效，并沿用既有本地偏好存储，不新增 Go 配置或联网操作。“关于”复用 App 已校验的 Go 版本信息，不重复发起请求；未连接时明确提示不可用，未知构建值显示本地化占位。
- 设置面板与顶部栏共用 LanguageSwitcher 横向胶囊、键盘逻辑和语言状态，不维护两套偏好；选项完整语言名通过 `aria-label` / `title` 提供，不依赖语言简写传达读屏名称。
- 语言选项直接在胶囊内展开，不使用视口定位、顶层 Popover 或外部关闭监听。聚焦当前语言会展开选项，点击选择不关闭设置窗；Esc 保留设置对话框原有关闭行为，焦点离开胶囊且鼠标移出后收起。
- 不包含尚未实现的邮箱、同步、通知或数据库设置。设置弹窗使用独立 `settings` 中英文命名空间，不将文案堆到 common。
- 弹窗适配小窗口，可在可用高度内滚动；进入动效遵守减少动态效果偏好。组件卸载会关闭原生模态层；StrictMode 过期 close 通知不能误关重新打开的弹窗。
- jsdom 不实现原生 dialog API，单测只模拟 open 状态和异步 close 通知；焦点循环、背景模糊和恢复焦点必须另外使用真实浏览器验证。

## 消息卡片

- 底部铃铛按钮与设置按钮同行；点击展开非模态消息卡片，包含标题、铃铛空态及“暂无新消息”，不对背景加模糊，也不阻止操作其他功能。
- 支持再次点击铃铛、关闭按钮、Esc、外部点击或焦点移出时收起；显式关闭后恢复铃铛焦点，外部点击不抢走目标控件焦点。窗口失焦、缩放或组件卸载时清理弹出状态及监听。
- 当前仅实现消息入口和空态，没有接入真实应用通知服务，不伪造通知记录或未读数；它不是邮件收件箱，也不代表托盘或系统通知能力已实现。
- 文案使用独立的 `messages` 中英文命名空间，样式复用亮暗主题令牌。

## 图标资源

- `frontend/public/brand/omnimail.svg` 与 `omnimail-256.png` 恢复为 `OmniMail_Icon_Kit` 原始标准版，分别与图标包内对应文件逐字节一致。只保留蓝色主体及信封自身的白色，蓝色圆角以外透明；工作台也不额外叠加 CSS 底座。
- 用标准版 PNG 和已锁定的 Wails 工具重新生成 16、24、32、48、64、128、256 像素 ICO；各尺寸均使用完整标准图形，不加白边，不混入简化版。Windows 构建自动嵌入资源，供资源管理器、桌面快捷方式、任务栏及 Alt+Tab 使用；PNG 同时通过 Go embed 提供给 Wails。
- 本次不自动创建或改写用户的桌面快捷方式、不修改已有任务栏固定项。Windows 可能缓存旧快捷方式图标；需要时重新固定更新后的程序，不自动重置系统图标缓存。
- 当前没有托盘功能，也未构建 macOS 应用包；不将资源包中的其他平台图标复制到未使用的目录。
