# 搜索页

> 状态：草稿 | 负责人：@design-lead | 最后更新：2026-10-15
> 相关：[FEAT-0005 本地搜索](../../01-product/features/FEAT-0005-local-search.md) · [主界面](inbox.md)

## 目标与入口

入口：`Ctrl/Cmd+K`、点击顶部搜索框、`/` 键。目标：输入即见，结果可解释，能快速收窄。

## 布局

```
┌───────────────────────────────────────────────────────────────┐
│ 🔍 [发票 2025                       ] ✕   搜索范围：全部账号 ▾ │ 搜索条 40px
│ 建议：from:  subject:  has:attachment  after:                  │ 提示行（空态）
├───────────────────────────────────────────────────────────────┤
│ 结果 1-50 / 共 214 封          排序：相关度 ▾                  │
│ [MailRow]  主题中命中词高亮                                    │
│ [MailRow]  摘要中命中词高亮                                    │
└───────────────────────────────────────────────────────────────┘
```

## 区域与元素

| 元素 | 规格 |
| --- | --- |
| 搜索输入 | `Input kind=search`，autofocus；输入停顿 150ms 触发 |
| 范围选择 | 全部账号 / 指定账号；与结果同步更新计数 |
| 语法提示 | 空态或首次使用时展示可点击的语法 chip |
| 结果行 | 复用 [MailRow](../components/mail-row.md)，主题与摘要中的命中以 `<mark>` 高亮 |
| 结果计数 | `1-50 / 共 N 封`，加载中显示 `搜索中…` |
| 排序 | 相关度（默认）/ 时间 |

## 交互与状态

| 场景 | 行为 |
| --- | --- |
| 输入中 | 保留上次结果并降低不透明度，避免闪烁；新结果到达即替换 |
| 无结果 | 空态：`没有找到匹配 "QUERY" 的邮件` + `清除筛选` + `扩大搜索范围（含已删除）` |
| 语法错误 | 不报错：整串作为字面量搜索，顶部提示 `已按完整文本搜索` |
| 结果降级 | 单字中文查询时提示 `短词结果可能不完整` |
| 点击结果 | 打开详情（列表上下文切换为搜索结果集） |
| 清除 | `✕` 或 `Esc` 返回原列表与原滚动位置 |
| 搜索耗时显示 | 开发模式显示 `elapsedMs`，生产隐藏 |

## 键盘操作

| 键 | 动作 |
| --- | --- |
| `Ctrl/Cmd+K` | 聚焦搜索（任意位置） |
| `Esc` | 清空并返回原视图 |
| `↓` | 从输入框进入结果列表 |
| `Enter` | 打开选中结果 |
| `Ctrl/Cmd+Enter` | 打开并保持搜索（新窗口/覆盖层） |

## 数据依赖

`Search.Query`（含 `accountIds`、`mailboxes`、`limit`）。

## 验收要点

- [ ] 输入 3 个字符到出结果 < 300ms（1 万封规模）。
- [ ] 快速连续输入不出现结果错乱（旧响应被丢弃）。
- [ ] 中文、英文、混合查询均有稳定结果；命中词正确高亮。
- [ ] 返回原视图时滚动位置与选中项保持。
- [ ] 语法 chip 点击后自动插入并聚焦到需填写位置。
