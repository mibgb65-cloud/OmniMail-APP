## 当前实现（2026-10-30）

- 左侧栏当前宽度为 240px（由 208px 适度加宽），标题栏起点通过共享 token 同步对齐；
  1280 最小原生窗口保持不变，长地址继续省略并通过完整提示读取，避免一味挤占正文区域。
- 原生桌面窗口最小宽度为 1280 逻辑像素（高度仍为 600），由 Wails 按 DPI 限制，
  不用 CSS 撑出横向溢出；默认 AI 展开时保留列表和正文空间。更窄的浏览器预览不等同
  当前原生桌面支持范围，见 [TASK-0075](../../07-tasks/active/TASK-0075-window-minimum-width.md)。
- “写邮件”在主工作区右侧进入编辑，保留导航与列表；暂时浏览其他邮件/账号不会清除本次编辑，
  From 不随浏览自动切换。撰写时隐藏分析面板并暂停针对旧阅读项的写操作，返回后恢复；
  具体会话限制与发送保护见 [撰写工作区](compose.md)，不把内存暂存称为持久草稿。
- 桌面邮件视图已接线现有 Go 邮件接口，保留通栏工具条及列表/阅读器双列。
  真实控制器初始读取失败时显示安全错误与“重新加载邮箱”，不再退回“尚未接入”的占位页；
  无控制器的设计预览仍保留。浏览器没有原生桥接时明确提示桌面服务限制，不代表已验证真实服务商。
- 邮件列表取消“上一页 / 下一页”，使用列表自身滚动容器无限追加；
  距底部约 160px 时请求下一批，复用每次 100 条的 `Messages(account, folder, offset)`。
- 邮件列表复用 `ScrollArea edgeFade`：仅在对应边缘还有隐藏内容时提供 16px 的透明
  `mask-image: linear-gradient(...)` 羽化，到达首尾/无溢出时对应边缘保持清晰。
  不用背景色伪元素遮挡；分栏边框和滚动轨道不参与遮罩，深浅背景通用。
  无限加载、重试焦点、追加不重挂载及查询切换回顶保持，见
  [TASK-0067](../../07-tasks/archive/2026/11/TASK-0067-mail-list-edge-fade.md)。
- 邮件列表、阅读区和其他滚动面板统一默认保留槽位但透明；仅滚动或鼠标精确进入滚动槽时淡入，
  内容悬浮/焦点停留不常显。停止滚动 800ms 后以 160ms 淡出，槽位悬浮/拖拽期间保留，
  无上下箭头，不改变无限加载及阅读器/iframe 的滚动结构，详见 [滚动条规范](../components/scroll-area.md)。
- 真实邮件行采用圆角分组布局：发件人与右侧日期/时分区同行，主题最多两行并保持稳定行高；
  未读使用圆点与字重，选中使用浅填充和侧边标识，悬停与键盘焦点单独呈现。
  发件人首字仅为本地装饰占位，不请求联系人照片；列表不超过 260px 时隐藏占位，优先保留信息。
- 列表使用 `clamp(232px, 24vw, 340px)`，最多占邮件双列区域的 48%，保留阅读区空间。
  右侧使用上下两行本地化日期及 24 小时 `HH:mm`，跨年保留年份；
  无效时间仍显示占位，`datetime` 保留真实 ISO 时间，骨架也有日期/时分两条占位。
  完整发件人/主题/时间与已读状态通过无障碍名称和统一 Tooltip 提供；
  超长 Tooltip 按共用 1024 字符上限截断，邮件原文与阅读区不变。
- 读取串行、按邮件 ID 去重，失败保留已加载邮件并显示安全错误与“重试加载”，
  不由滚动事件循环重试。短批次后停止，结束说明只覆盖已同步的本地邮件。
- 追加不清空当前阅读项或重建滚动容器；切换邮箱/分类或重置视图时取消旧请求、
  清空累计范围并回到顶部。列表可聚焦，键盘滚动同样触发读取，并提供 busy/status 提示。
- 切换邮箱/分类首批读取时，邮件列表使用与详情相同的单层流光骨架，采用发件人/日期/主题行占位，
  不显示旧账号内容或提前闪现空态。约 280ms 最短展示与网络并行，慢请求就绪后不额外等待。
  首批完成后首屏邮件行按实际纵向位置依次淡入上移，沿用详情的 320ms 入场及有界错峰，
  总入场时间不超过约 760ms；屏外行直接保持最终样式，不为大邮箱逐条排队。
  后台刷新、自动已读、同范围筛选和分页追加不重新遮罩/重播；快切会清理旧计时器与动画，
  滚动、点击或聚焦可立即取消到最终样式，减少动态效果时无最短等待/流光/行入场。
  首批错误立即显示重试，真正空态在首批完成后展示；见
  [TASK-0069](../../07-tasks/archive/2026/11/TASK-0069-mail-list-switch-transition.md)。
- 账号仍按既有间隔轮询；同步时间、运行/错误/账号状态变化或显式刷新时，
  重新读取已加载范围并原子发布，避免轮询把累计列表替换成最后一批。
- 已成功读取的邮箱状态轮询暂时失败时，保留邮件/账号缓存视图并显示安全原因，恢复后正常重验。
  同步失败、正在同步、重授权、已断开与真正空列表分别呈现，不用“暂无邮件”掩盖失败；
  同步错误可重新同步，重授权只提示实际状态，不虚构尚未实现的登录入口。
- 正文仍按需读取，但使用独立、有界的前台通道，不再因同账号后台同步返回 BUSY；
  每账号一个正文连接、一个标记连接和一个同步连接，正文与标记分别使用独立全局额度。
  同步状态轮询或星标列表刷新不取消/重发正在读取的正文；仅切换邮件、手动重试/重取或卸载取消。
  对账号撤销等少数短暂 BUSY 保留有界兼容重试，其他错误提供“重新加载正文”，不盲目循环重试。
  HTML 正文经清洗后在无脚本 iframe 中显示，纯文本邮件仍作为文本显示；
  不把摘要已缓存描述为正文已下载。旧文本缓存可显式重新获取完整内容，失败不丢原缓存。
- 设置的“通用设置 → 邮件图片”提供不显示、仅内嵌（默认）、全部三档，
  本机保存并即时联动阅读器；远程图片默认没有网络请求，仅本封授权不传播到其他邮件。
- 普通后台同步进度不再占用列表顶部；所选邮箱范围的运行/续排状态由工具栏同步按钮的文本、
  旋转图标及统一提示呈现。账号同步错误、重授权、受限及断开状态集中在左侧状态点和管理窗，
  不在邮件列表顶部重复放置告警；列表自己的读取/操作失败及初始账号加载失败仍明确显示。
- 邮件行具有独立的标星/取消按钮，不与打开邮件按钮嵌套。操作通过 IMAP 增减 `\\Flagged`，
  验证 UIDValidity 和服务器 STORE 回执后才写 SQLite，使用非 SILENT 回执减少一次额外 FETCH。
  界面先显示期望星标与保存中状态，不同邮件独立提交；失败仅回滚对应邮件并提示，不冒充已落库。
  同步 FETCH 的过期 Flags 快照在标记提交后丢弃重取，避免覆盖新状态。
  星标分类保留尚在保存的本账号项目，服务器完成后的数据库快照接管临时显示；
  本期不含持久离线变更队列，真实请求仍受网络和服务商连接额度约束。
- 已下载的文本与原始 HTML 保存在数据库，附件与内嵌图保存在持久文件并由数据库关联；
  关闭/重开数据库后可读取。按需下载不等于仅放内存，尚未自动下载所有未打开邮件的正文。
- IMAP 摘要使用标准 `BODY.PEEK[HEADER]`，兼容 ENVELOPE 响应差异；不读取正文/附件或标记已读。
  头部复用 1 MiB 预算并校验 literal 长度，UID/Flags/日期/大小必须完整后才发布整批。
  连接中断、超时与真正协议/MIME错误分开，异常 literal 先断线再释放缓冲通道，避免正文失败后账号卡忙。
- 后台仍有 60 秒硬期限；剩余时间不足 20 秒时不再启动下一批，已成功的批次和 UID/scan 游标保留，
  通过 More 和原 5 秒续排恢复。周期内已完成文件夹不反复从头核对；结束后下一周期正常重验。
  前台暂占账号时保留续排，完成或真实错误后停止旧续排；真实错误仍允许手动/既有周期重试。
  这不是延长超时或宣称所有正文都已下载。
- “我的邮箱”标题旁提供“按服务商分组”切换按钮（含按下状态与切回平铺提示），默认平铺，
  仅本次会话保留模式。分组依据真实 providerCode，不按地址猜测；网易 163/126 合为网易品牌组，
  其他品牌保持独立，未知服务商安全显示其代码并使用通用图标。
  服务商行使用本地图标与邮箱个数，标示当前选中账号所在组，但进入/返回不切换实际账号。
  进入后只显示该组账号，沿用原状态点及单账号重试；返回恢复服务商焦点，
  组消失安全退回且重加不自动钻入。全局“全部邮箱”、添加及管理入口始终保留；
  内层点击“全部邮箱”会全局选择并回到服务商入口，不冒称服务商级查询。
  滚动视口继续透明 mask 羽化，面包屑留在视口外，不遮挡状态浮层；
  详见 [TASK-0074](../../07-tasks/active/TASK-0074-mailbox-provider-browser.md)。
- “我的邮箱”使用独立轻量单行列表：全部邮箱与账号选中态互斥，账号名/邮箱省略显示，状态点固定在右侧列上下对齐，
  已同步为绿色，失败或需要重新登录为红色，运行/续排为蓝色，未同步/已断开为中性色。
  悬浮、聚焦或点击状态点打开同风格状态浮层，显示完整邮箱和语义状态；成功显示“已同步 xx 封邮件”，
  状态点按钮本身在悬浮和浮层展开时保持透明，不叠加独立灰色底块；整行状态和键盘焦点轮廓不变。
  数量由 `Accounts.messageCount` 从本地数据库按账号跨文件夹聚合，并非当前分页数量或远端全量。
  不同文件夹的同一 Message-ID 仍按独立本地记录计数；数量缺失时只显示“已同步”，不伪造零。
  失败浮层显示安全错误说明和“重新同步”，只重试对应账号，不切换选中账号、不清空筛选；
  重试失败保留安全提示，认证失效则提示重新登录，不提供无效同步入口。
  浮层以 Portal / 原生 Popover 规避列表裁切，支持键盘进入重试、Esc 收起、外部点击/滚动/窗口失焦收起。
  同步运行和批次续排期间，仅在外层 2px 区域显示 4 秒一圈的顺时针 conic-gradient 流光，
  沿用原圆角和卡片底色；减少动态效果时静止，高对比度模式使用系统描边。
  外侧邮箱行不再渲染断开入口，悬停/焦点/触控下也不出现；“我的邮箱”标题右侧的设置按钮
  打开独立“邮箱账号管理”浮窗。沿用设置页双栏、主题和固定底栏：左侧选择管理账号，
  右侧显示完整邮箱、服务商、状态、本地数量、同步及账号连接操作，管理选择不切换工作区邮箱。
  管理窗左侧账号使用与添加页一致的本地服务商品牌图标；仅自定义/未知服务商使用通用信封，
  不按邮箱文本猜品牌，也不从第三方请求图像。
  断开只在管理窗内提供，已断开账号不重复显示。确认复用 `DialogFrame` 的圆角、主题色、遮罩和退出动效，明确展示账号及“保留已下载邮件”的说明，
  默认聚焦取消，确认才调用断开；不再使用 `window.confirm`，不改变原断开/清除凭据语义。
  操作进行中禁用切换/关闭/重复提交；失败只在管理窗显示安全错误，不误标为全局账号读取失败。
  管理窗内的添加入口在管理窗退出后复用现有添加向导，不同时堆叠两个主浮窗。
  子确认关闭恢复原按钮或完成按钮，管理窗关闭恢复标题设置入口；窄窗上下排布且内容独立滚动。
  长账号省略，完整信息也可通过共用 Tooltip 查看；悬停/选中显式覆盖全局主按钮配色。
  分类提示跟随实际接入状态，不再对已连接邮箱宣称“邮件功能尚未接入”。

## 目标与入口

邮件工具栏在归档前提供“翻译标题和正文”。仅选中且完整缓存邮件可用，
选择目标语言并授权后调用第三方，源语言由模型自动判断；结果可切回原文，
不改原邮件和附件。详见 [邮件翻译](mail-translation.md)。

应用启动后的默认页面。目标是让用户 3 秒内掌握"有哪些新邮件、来自哪些账号、我需要处理哪一封"。

## 区域与元素

### 侧栏（240px，可折叠至 56px）

| 区块 | 内容 |
| --- | --- |
| 统一收件箱 | 固定第一项，含总未读数徽标 |
| 账号分组 | 每个启用账号：名称（可折叠）+ 收件箱/未读/已发送/草稿/垃圾箱 |
| 账号着色 | 账号名左侧 8px 色点（`--color-account-N`） |
| 底部 | 设置、添加账号、折叠按钮 |

- 未读数徽标：> 999 显示 `999+`；为 0 时不显示。
- 账号同步中：账号名右侧转圈小图标；出错：红色感叹号 + tooltip 显示原因。

### 列表头

- 标题随所选视图变化：`统一收件箱` / `ACCOUNT_LABEL · 收件箱`。
- 右侧：排序（最新/最旧）、密度切换、批量选择模式。
- 当前筛选条件以 chip 显示（如 `仅未读` `有附件`），可单独移除。

### 列表

见 [MailRow](../components/mail-row.md) 与 [VirtualList](../components/virtual-list.md)。

### 详情占位

未选中时展示：应用图标或空态插画、主提示文案、快捷键提示（`j/k` 浏览、`c` 撰写、`Ctrl+K` 搜索）。

## 交互与状态

| 场景 | 行为 |
| --- | --- |
| 首次启动无账号 | 全屏引导：添加账号（主按钮）+ 说明本地存储与隐私 |
| 同步中 | 列表顶部细进度条（1px，不遮挡内容） |
| 新邮件到达 | 列表顶部插入并高亮 600ms；若在"统一收件箱"，账号徽标 +1 |
| 加载更多 | 距底部 200px 触发，底部显示 3 行骨架 |
| 空列表 | 空态：`收件箱是空的` + `立即同步` |
| 同步失败 | 顶部 banner：`同步未完成：AUTH_INVALID_MESSAGE` + `重新授权` |
| 离线 | 顶部细条：`离线模式，更改将在联网后同步` |
