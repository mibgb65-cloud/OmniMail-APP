## 当前实现（2026-10-30）

- 桌面邮件视图已接线现有 Go 邮件接口，保留通栏工具条及列表/阅读器双列。
  真实控制器初始读取失败时显示安全错误与“重新加载邮箱”，不再退回“尚未接入”的占位页；
  无控制器的设计预览仍保留。浏览器没有原生桥接时明确提示桌面服务限制，不代表已验证真实服务商。
- 邮件列表取消“上一页 / 下一页”，使用列表自身滚动容器无限追加；
  距底部约 160px 时请求下一批，复用每次 100 条的 `Messages(account, folder, offset)`。
- 真实邮件行采用圆角分组布局：发件人与本地化短日期同行，主题最多两行并保持稳定行高；
  未读使用圆点与字重，选中使用浅填充和侧边标识，悬停与键盘焦点单独呈现。
  发件人首字仅为本地装饰占位，不请求联系人照片；列表不超过 260px 时隐藏占位，优先保留信息。
- 列表使用 `clamp(232px, 24vw, 340px)`，最多占邮件双列区域的 48%，保留阅读区空间。
  跨年日期保留年份，完整发件人/主题/时间与已读状态通过无障碍名称和统一 Tooltip 提供；
  超长 Tooltip 按共用 1024 字符上限截断，邮件原文与阅读区不变。
- 读取串行、按邮件 ID 去重，失败保留已加载邮件并显示安全错误与“重试加载”，
  不由滚动事件循环重试。短批次后停止，结束说明只覆盖已同步的本地邮件。
- 追加不清空当前阅读项或重建滚动容器；切换邮箱/分类或重置视图时取消旧请求、
  清空累计范围并回到顶部。列表可聚焦，键盘滚动同样触发读取，并提供 busy/status 提示。
- 账号仍按既有间隔轮询；同步时间、运行/错误/账号状态变化或显式刷新时，
  重新读取已加载范围并原子发布，避免轮询把累计列表替换成最后一批。
- 已成功读取的邮箱状态轮询暂时失败时，保留邮件/账号缓存视图并显示安全原因，恢复后正常重验。
  同步失败、正在同步、重授权、已断开与真正空列表分别呈现，不用“暂无邮件”掩盖失败；
  同步错误可重新同步，重授权只提示实际状态，不虚构尚未实现的登录入口。
- 正文仍按需读取，但使用独立、有界的前台通道，不再因同账号后台同步返回 BUSY；
  每账号一个正文连接、一个标记连接和一个同步连接，正文与标记分别使用独立全局额度。
  同步状态轮询或星标列表刷新不取消/重发正在读取的正文；仅切换邮件、手动重试/重取或卸载取消。
  对账号撤销等少数短暂 BUSY 保留有界兼容重试，其他错误提供“重新加载正文”，不盲目循环重试。
  HTML 正文经清洗后在无脚本 iframe 中显示，纯文本邮件仍作为文本显示；
  不把摘要已缓存描述为正文已下载。旧文本缓存可显式重新获取完整内容，失败不丢原缓存。
- 设置的“通用设置 → 邮件图片”提供不显示、仅内嵌（默认）、全部三档，
  本机保存并即时联动阅读器；远程图片默认没有网络请求，仅本封授权不传播到其他邮件。
- 普通后台同步进度不再占用列表顶部；所选邮箱范围的运行/续排状态由工具栏同步按钮的文本、
  旋转图标及统一提示呈现。错误、重授权、断开账号及重试提示仍保留，不隐藏实际失败。
- 邮件行具有独立的标星/取消按钮，不与打开邮件按钮嵌套。操作通过 IMAP 增减 `\\Flagged`，
  验证 UIDValidity 和服务器 STORE 回执后才写 SQLite，使用非 SILENT 回执减少一次额外 FETCH。
  界面先显示期望星标与保存中状态，不同邮件独立提交；失败仅回滚对应邮件并提示，不冒充已落库。
  同步 FETCH 的过期 Flags 快照在标记提交后丢弃重取，避免覆盖新状态。
  星标分类保留尚在保存的本账号项目，服务器完成后的数据库快照接管临时显示；
  本期不含持久离线变更队列，真实请求仍受网络和服务商连接额度约束。
- 已下载的文本与原始 HTML 保存在数据库，附件与内嵌图保存在持久文件并由数据库关联；
  关闭/重开数据库后可读取。按需下载不等于仅放内存，尚未自动下载所有未打开邮件的正文。
- IMAP 摘要使用标准 `BODY.PEEK[HEADER]`，兼容 ENVELOPE 响应差异；不读取正文/附件或标记已读。
  头部复用 1 MiB 预算并校验 literal 长度，UID/Flags/日期/大小必须完整后才发布整批。
  连接中断、超时与真正协议/MIME错误分开，异常 literal 先断线再释放缓冲通道，避免正文失败后账号卡忙。
- 后台仍有 60 秒硬期限；剩余时间不足 20 秒时不再启动下一批，已成功的批次和 UID/scan 游标保留，
  通过 More 和原 5 秒续排恢复。周期内已完成文件夹不反复从头核对；结束后下一周期正常重验。
  前台暂占账号时保留续排，完成或真实错误后停止旧续排；真实错误仍允许手动/既有周期重试。
  这不是延长超时或宣称所有正文都已下载。
- “我的邮箱”使用独立轻量列表：全部邮箱与账号选中态互斥，账号名/邮箱与短状态分层显示，
  悬停/选中显式覆盖全局主按钮配色。断开按钮默认隐藏，在悬停、键盘焦点或触控场景露出，
  使用幽灵样式、保留确认，不删除缓存或变更原断开语义。长账号省略，完整信息通过共用 Tooltip 查看。
  分类提示跟随实际接入状态，不再对已连接邮箱宣称“邮件功能尚未接入”。
- 筛选仅针对已加载邮件的主题/发件人，未接入全文搜索；没有匹配项时说明可清空筛选继续加载。
  顶部未读计数也仅覆盖已加载范围，不冒充邮箱总量。
- 仓储 offset 上限仍为 1,000,000，触达边界会说明读取上限而不是谎称全部加载；
  本轮未改成 API 草稿中的游标协议，也未引入虚拟列表。

## 目标与入口

应用启动后的默认页面。目标是让用户 3 秒内掌握"有哪些新邮件、来自哪些账号、我需要处理哪一封"。

## 区域与元素

### 侧栏（240px，可折叠至 56px）

| 区块 | 内容 |
| --- | --- |
| 统一收件箱 | 固定第一项，含总未读数徽标 |
| 账号分组 | 每个启用账号：名称（可折叠）+ 收件箱/未读/已发送/草稿/垃圾箱 |
| 账号着色 | 账号名左侧 8px 色点（`--color-account-N`） |
| 底部 | 设置、添加账号、折叠按钮 |

- 未读数徽标：> 999 显示 `999+`；为 0 时不显示。
- 账号同步中：账号名右侧转圈小图标；出错：红色感叹号 + tooltip 显示原因。

### 列表头

- 标题随所选视图变化：`统一收件箱` / `ACCOUNT_LABEL · 收件箱`。
- 右侧：排序（最新/最旧）、密度切换、批量选择模式。
- 当前筛选条件以 chip 显示（如 `仅未读` `有附件`），可单独移除。

### 列表

见 [MailRow](../components/mail-row.md) 与 [VirtualList](../components/virtual-list.md)。

### 详情占位

未选中时展示：应用图标或空态插画、主提示文案、快捷键提示（`j/k` 浏览、`c` 撰写、`Ctrl+K` 搜索）。

## 交互与状态

| 场景 | 行为 |
| --- | --- |
| 首次启动无账号 | 全屏引导：添加账号（主按钮）+ 说明本地存储与隐私 |
| 同步中 | 列表顶部细进度条（1px，不遮挡内容） |
| 新邮件到达 | 列表顶部插入并高亮 600ms；若在"统一收件箱"，账号徽标 +1 |
| 加载更多 | 距底部 200px 触发，底部显示 3 行骨架 |
| 空列表 | 空态：`收件箱是空的` + `立即同步` |
| 同步失败 | 顶部 banner：`同步未完成：AUTH_INVALID_MESSAGE` + `重新授权` |
| 离线 | 顶部细条：`离线模式，更改将在联网后同步` |

## 键盘操作

| 键 | 动作 |
| --- | --- |
| `j` / `↓` | 下一封 |
| `k` / `↑` | 上一封 |
| `Enter` | 打开/进入详情 |
| `u` | 切换已读/未读 |
| `s` | 切换星标 |
| `e` | 归档 |
| `Del` / `#` | 移到垃圾箱 |
| `c` | 撰写 |
| `r` / `a` / `f` | 回复 / 全部回复 / 转发（需详情打开） |
| `Ctrl/Cmd+K` | 聚焦搜索 |
| `g i` | 跳统一收件箱；`g 1..6` 跳出第 N 个账号 |
| `?` | 快捷键帮助 |

## 数据依赖

`Account.List`、`Mail.Page`、`Sync.Status`；订阅 `mail:new`、`mail:updated`、`sync:*`。

## 验收要点

- [ ] 1280×820 下三栏比例舒适，无横向滚动。
- [ ] 未读数为 0 时徽标隐藏，列表不跳动。
- [ ] 新邮件插入时当前滚动位置不跳变（若用户已向下滚动，仅显示"↑ 1 封新邮件"提示条）。
- [ ] 全部交互键位可用且不与输入框冲突（输入框聚焦时快捷键失效）。
- [ ] 深色主题下账号色条仍可区分（6 色对比度达标）。
- [ ] 侧栏折叠后图标有 tooltip，键盘可达。
