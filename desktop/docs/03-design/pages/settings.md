# 设置

> 状态：已实现（能力边界见下） | 最后更新：2026-11-01 | 关联：TASK-0078

## 目标与入口
从侧栏底部“设置”打开原生模态窗口，不新增独立路由，不卸载邮件工作区。

## 布局与内容
左侧为可独立滚动的垂直分类列，右侧为固定标题、关闭按钮和可滚动面板。
保留通用设置，补齐七个分类；无底部“更改即时生效”提示和“完成”按钮。

| 分类 | 当前实现 |
| --- | --- |
| 通用设置 | 界面语言、三态外观滑块，以及关闭主窗口时的询问／退出／后台偏好 |
| 邮箱设置 | 显示已添加邮箱实际数量；退出设置后复用邮箱管理窗口，支持已有的添加、重试、断开流程 |
| 通知设置 | 明确说明系统通知、提示音和免打扰尚未接入，不显示无效开关 |
| 邮件查看 | 复用正文跟随暗色模式与邮件图片策略，本地保存、即时生效 |
| AI 设置 | 明确未接入 AI 服务，不提供无效的模型/密钥输入，不发送邮件给 AI 服务商 |
| 存储情况 | 通过 StorageBridge.Usage 读取本机当前数据目录的实际文件字节数 |
| 关于 | 复用已校验的版本、平台、构建及桌面连接诊断 |
| 软件更新 | 显示实际安装版本；明确更新服务尚未接入，不宣称已是最新版 |

## 真实存储口径
- 邮件数据：`omnimail.db`、`omnimail.db-wal`、`omnimail.db-shm`；全文索引在 SQLite 内，不重复单列。
- 附件缓存：`attachments/` 下的实际文件，包括内嵌图片与下载中的临时文件。
- 运行日志：`logs/`；数据库备份：`backups/`；剩余文件计入其他。
- 统计实际文件长度，不是磁盘分配块、剩余空间、磁盘总容量或服务商邮箱配额；不扫描应用目录以外的附件导出位置。
- 使用进程配置确定的数据目录；前端无路径参数。`os.Root` 约束文件访问，不跟随符号链接，不读取邮件内容。
- 服务端 10 秒、100,000 个目录项及 JavaScript 安全整数边界；前端 12 秒取消 IPC。
- 已消失文件按同步/日志轮转时的快照忽略；其他读取错误或超限整体失败，不返回部分占用冒充完整统计。
- 数据同步期间可能变化；按需进入页面或手动刷新重新统计，不持续高频扫描。

## 交互与状态
- 外观采用紧凑胶囊三段单选滑块，日／月／显示器图标搭配亮色／暗色／系统短标签，
  读屏使用完整名称。选中胶囊以主题自适应黑白反差平滑移动；支持点击、方向键及 Home/End，
  Tab 只进入当前选项，减少动态效果时无滑动动画。
- 外观偏好保存为 `light`、`dark` 或 `system`，兼容原有亮/暗偏好；初次或非法值默认跟随系统。DOM 的实际主题仍为 light/dark，不直接使用 system 作为配色。
- 选择跟随系统立即应用当前系统外观，并响应后续变化；固定亮/暗不受系统变化影响。顶部快捷切换仍为亮/暗二态，使用后转为对应固定偏好。
- 外观保存失败仍在本会话生效，界面显示安全提示；重新选择并写入成功后清除提示。
- 邮件图片的三种策略使用整行选择卡片：图标、完整读屏名称、独立推荐标签和右侧选中勾选。
  保持 none/inline/all 及默认 inline，仍沿用原本的隐私说明与本地偏好，未改变远程图片加载行为。
  原生 radio 语义不变；Tab 进入当前项，方向键和 Home/End 可选择，支持亮暗和减少动态效果。
- 关闭主窗口时可选每次询问、退出应用、后台运行。偏好由 Go 在当前应用数据目录的
  `window-close.json` 中持久化，不使用前端缓存代替原生关闭决策；损坏或缺省回退询问。
- 关闭偏好不再使用原生下拉菜单，与外观共用紧凑三段胶囊样式；显示询问/退出/后台短标签与图标，
  读屏保留完整名称。读取中不冒充已保存默认值，保存失败保持原选项，保存/待确认期间禁用，
  不支持后台时只禁用该项。方向键/Home/End 跳过禁用项，异步保存后恢复键盘焦点但不抢走已移出的焦点。
- 未设定时，自绘标题栏关闭、Alt+F4 等原生窗口关闭均先取消默认销毁，显示同一确认窗口。
  用户必须选择行为，记住选择默认不勾选；未记住仅本次生效。勾选后先保存成功再执行，
  失败保持窗口和弹窗，可取消勾选后执行单次操作。
- 关闭确认采用按内容收拢的居中紧凑窗口，右上角、取消及 Esc 均取消本次关闭；
  主按钮等待选择后启用，处理期间禁止重复确认和取消交错。不通过点击空白背景意外关闭。
- 后台模式隐藏而不销毁主窗口，继续运行现有同步。Windows/macOS 提供托盘点击恢复、
  打开和明确退出菜单；再次启动应用也显示原有窗口。Linux 当前不开放后台选项，避免无恢复入口。
- 托盘“退出”是明确退出，不再遵循“关闭窗口时后台运行”的偏好。未实现开机自启动。
- 点击分类及上下箭头、Home/End 切换；Tab/Shift+Tab 在当前可见控件首尾循环，隐藏面板不进入焦点序列。
- 右上角关闭、Escape、真正的背景点击关闭；保留原生模态与退出动画，打开账号管理要等待设置完全关闭。
- 存储页进入即加载；加载时禁止重复刷新。成功显示总量、五类分布和百分比；空目录显示真实零值，无 NaN。
- 统计失败只显示本地化错误及重试，不泄漏路径、内部错误或用示例数据兜底。
- 切离存储页和卸载取消请求，忽略过期响应；重新进入获取新快照。
- 中英文文案位于独立 `settings` 命名空间，沿用语义主题令牌与减少动态效果偏好。
- “关于”页不使用嵌套圆角卡片：取消外层卡片，改用 1px 细分隔线划分区块；桌面服务连接区只保留
  小标题、右上文字按钮、状态行和等宽元数据列，连接失败态用左侧 2px 语义色竖线表达。
  下一阶段的三个步骤为“序号＋标题＋说明”的纯文本三列，≤680px 回落单列；元数据列用
  `auto-fit` 自动换列，不出现横向滚动。
