# 邮件 AI 助手

> 状态：已实现 | 日期：2026-11-02 | 关联：TASK-0090～0095（已提交归档）

## 入口与范围
- “设置 → AI 设置”配置一组 OpenAI-compatible API base URL、模型和输出语言。
- 主工作区右侧 AI 面板主动分析选中且完整缓存的邮件，显示摘要、要点、待办和关键信息。
- 待办/关键信息附原文引文；负责人和日期仅允许保留引文中的原始文本，未知显示“未明确”。
- 回复意图/语气由用户填写，生成后仅点击“采用”才进入撰写区。采用不设置收件人或主题，
  不调用 SMTP；用户须检查内容、填写收件人与主题并明确发送。
- 已有编辑、发送中或结果不确定的会话禁止被 AI 覆盖。没有已连接发件账号时只能阅读建议。
- 保留独立的 B 站邮件翻译；配置通用 AI 不更换翻译服务，也不将翻译模型当作通用助手。

## 配置与外发
- 不默认保存或启用公网服务；本页单封入口不自动分析/上传/重试，不自动切换服务商。
  每日后台功能须另行授权，见 [待办与每日邮件需求](requirements-tasks.md)；
  首次配置表单提供 DeepSeek 预填建议，仍须用户填写密钥并主动保存/授权。
- 云端只允许 HTTPS，HTTP 仅用于 localhost/回环 IP；不允许 URL 账号口令、query 或 fragment，
  地址应为 base URL，不填写 `/chat/completions`。拒绝跳转；本机 HTTP 不经代理，
  localhost 固定连接回环，避免 DNS/代理把本机例外变成公网明文外发。
- API Key 写入系统凭据库独立的 `omnimail/ai/<随机ID>` 条目，配置文件只记录引用，
  前端读取仅得到 hasKey。留空保留同一目的地密钥，换目的地不携带旧密钥。
- 原子写入配置成功后再删除旧密钥；保存失败清理新条目并保留旧配置。
  凭据清理失败仍安全报告，界面重新读取后端事实，不把失败响应当成完全没有发生。
- 明确授权后才允许外发标题和正文；正文自身的签名、地址、机密内容也可能发送。
  不读取邮箱登录凭据，不发送附件、图片或结构化收发件人头。
- 服务地址变化在界面取消授权勾选。手动连接测试只发送固定合成文本，不要求真实邮件外发授权。
  不承诺第三方不保存数据、不会训练或取消能撤回已发送文本。

## DeepSeek 默认配置（TASK-0095，2026-11-02）
- 首次未保存过配置时预填 `https://api.deepseek.com` 和 `deepseek-flash`；
  API 别名目前对应 V4.1-Flash-1017，来源见 [官方首次调用](https://api-docs.deepseek.com/)。
  不使用未经官方文档确认的 `deepseek-v4.1-flash` 标识，不承诺别名永久锁定版本。
- 已保存的地址/模型，包括用户主动保存的停用空配置，不会被默认值覆盖。
  显式“填入 DeepSeek 默认配置”会清除表单未保存的密钥并取消授权，不自动保存/外发；
  已使用官方根地址或 `/v1` 的配置保留原地址，避免无意义的目的地变更影响旧密钥。
- 仅官方 HTTPS 主机、标准 443 端口和根或 `/v1` 路径启用 DeepSeek 参数：
  `thinking.type=disabled`、`response_format.type=json_object`，消息中明确要求 json。
  参照 [思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)和
  [JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)；其他兼容服务不接收这些附加参数。
- 即使 stop 响应也可能只有空白；空白、仅 reasoning_content 或截断继续安全失败，不自动重试。
  连接测试和分析可能消耗服务方额度，需要用户自己的 API Key；B 站翻译不受影响。
- 没有真实 DeepSeek 密钥时只验证本地契约，不将模拟响应或官方文档称为真实模型调用验收。

## 分层与限制
```text
AISettings / MailAIPanel / useMailAI
  → lib/bridge/ai + 未知数据校验
  → AIBridge
  → AI service（授权、正文快照、生命周期、缓存）
  → aiapi（HTTP）/ AIStore（受限原子 JSON）/ CredentialStore（系统凭据）
```
- 不新增 SDK、依赖、数据库迁移、Agent、RAG 或可执行工具。
- 标题 4 KiB、正文 32 KiB；HTML-only 提取复用翻译的有界本地解析，不加载图片/链接。
- 非流式，一次最多一个通用 AI 外发任务；准备/请求/保存阶段可查询，超时 120 秒，
  前端 125 秒兜底；HTTP 连接/TLS 10 秒、响应头 60 秒、响应体最多 256 KiB。
- 严格结构化结果、每类最多 12 项、字符串长度限制，截断/空输出/未知字段不作为成功。
  引文必须逐字来自当前正文或标题；这只能验证来源，不保证摘要、任务含义准确。
- 邮件始终是不可信数据，系统规则与邮件 JSON 分离；结果始终文本渲染，
  不执行模型提出的操作、HTML、链接或命令。
- 429 采用 1～300 秒有界 Retry-After 冷却（缺省 30 秒），到期仍需手动重试，不自动外发。
- 翻译额外显示分段进度，保留最多 16 片限制；响应体超时/断流与格式错误分别处理。

## 缓存、取消与清理
- 按账号、邮件 ID、正文摘要、配置修订、动作、意图/语气及模板版本绑定本地缓存。
  配置修订涵盖目的地、模型、语言和密钥更新；改变正文或配置后旧结果不命中。
- 打开邮件只恢复分析缓存，不自动生成；回复缓存仅在相同意图/语气主动生成时复用。
- 缓存每类最多 128 文件、16 MiB，受限根目录与原子替换；缓存写失败保留结果并警告。
- 切换邮件、隐藏/关闭面板、进入撰写或变更配置会取消旧请求并丢弃迟到结果。
  重新展开不能保留已取消任务的忙状态。
- AI 设置的清理按钮需再次确认，只逐个删除白名单派生结果 JSON 及中断写入的已知格式临时文件，不递归删除目录，
  不删除邮件、附件、凭据、配置，也不撤销外发授权。
- 清理与结果写回互斥，并取消进行中的 AI/翻译任务，防止旧请求在清理后写回。
  界面缓存同时失效。派生缓存是本机文本，未宣称静态加密。

## 验证边界
- 后续的待办与每日分析是独立授权功能，见 [待办与每日邮件需求](requirements-tasks.md)；
  本页单封分析权限不能直接用于后台外发，待办不属于本页的可清理缓存。
- 使用合成正文、本地 HTTP fixture、临时数据目录及显式随机系统凭据条目验证。
- 普通测试不访问公网或真实邮箱。模型兼容性、语义质量、真实第三方限额与数据政策仍需
  用户配置服务后自行验收；本地门禁不等于原生操作验收或 CI 已通过。
