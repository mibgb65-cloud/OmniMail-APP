### 设计阶段的短句连通请求（历史记录）

只发送公开短句，没有读取或上传用户邮件：

```json
{
  "model": "Index-Translate-35B-A3B",
  "messages": [
    {
      "role": "user",
      "content": "请将以下文本翻译为中文，直接输出翻译结果，不要进行任何解释。\n\nHello, world!"
    }
  ],
  "temperature": 0,
  "max_tokens": 128,
  "stream": false,
  "chat_template_kwargs": {
    "enable_thinking": false
  }
}
```

实际 HTTP 200，响应 model 同上、finish_reason 为 stop，译文为“你好，世界！”。
128 是短句连通测试预算，不是生产邮件翻译上限；一次成功也不代表长期服务保证。

## 2. 当前交互

- 按用户指定位置，在顶部工具栏归档前提供翻译按钮；未选中/未完整读取/撰写中禁用。
- 默认目标简体中文，另支持英语、日语、韩语、德语、法语、西班牙语，独立于界面语言并保存到本机。
- 用户手动点击翻译；不在切换邮件或启动应用时自动上传。
- 首次对该服务授权，明确说明开启后仅在手动操作时发送标题与正文；
  翻译窗中可取消授权并“仅保存设置”，不发起翻译。
  未授权时 Go 后端同样拒绝请求，不只依赖前端弹窗。
- 成功后提供“原文 / 译文”切换，保留原邮件、附件和图片策略；首期译文使用段落化纯文本。
- 切换器位于工具栏翻译图标旁，左“原”右“译”，有完整结果时才展开，支持点击/拖动/键盘；
  不在正文上方增加控制栏。加载可由图标取消，错误使用工具栏浮层。
- 译文明确标为机器翻译，不写回原邮件；重要交易/合同等仍以原文为准。
- 请求中显示翻译中与取消，失败保留原文并可重试；不要把错误或空结果显示成成功。
- 此处是邮件内容翻译，不是已有 useTranslation 界面国际化，也不代表右侧 AI 分析已接入。

首次授权文案明确标题/正文外发，以及正文自身的敏感信息也会发送；
不会读取邮箱账户登录凭据，不发送附件或图片二进制。未获授权的敏感/公司邮件不应使用。
不能宣传“绝不保存/绝不用于训练”，因为本轮未找到该服务的此类保证。

## 3. 当前分层与接口边界

```text
MailToolbar / MailTranslationProvider / MailReaderPage
  → lib/bridge 封装
  → 薄 TranslationBridge
  → Go 翻译服务（授权、正文、去重、缓存、任务限制）
  → HTTP provider adapter
  → B 站固定 HTTPS endpoint
```

- 核心服务通过领域接口调用 provider，不反向依赖 Wails/React。
- 前端传邮件 ID、目标语言和取消信号；后端读取该邮件已缓存的标题、正文。
  不接收任意文件路径、可执行指令或任意第三方 URL。
- 使用 Go 直连规避 WebView CORS 限制，不启动额外 Python 代理；
  不把 b站登录 Cookie、邮箱凭据或任意伪造 Key 填入请求。
- endpoint/model 为经核对的 provider 配置，后续可扩展适配器，但不能在失败时悄悄换别家发送数据。
- AI 页已说明翻译入口与边界，移除“绝不会发送邮件”的过时承诺；
  翻译配置在工具栏/译文状态栏的翻译窗中，通用 AI 分析仍明确未实现。
- HTTP 使用 JSON subject/body 协议要求只翻译值，空值为空；严格解析两个字段，
  不使用未确认的 response_format 扩展或前端直连。

## 4. 正文与 HTML 处理

- 优先使用本地已缓存的纯文本正文；HTML-only 邮件在 Go 本地解析为正文文本，
  跳过 script/style/注释及图片数据，不为翻译加载外链图片或读取远程页面。
- 用户明确要求翻译 subject；除此之外不发送 from/to 等结构化头、附件、图片数据或完整原始 MIME。
  正文自身可能包含签名、地址和转发头，不能因此宣称正文已完全匿名。
- 正文不完整/超出邮件读取限制时，明确提示先完成正文读取，不假装已经翻译整封。
- 不直接把原 HTML 交给模型再以 innerHTML 显示。
  首期结果只作为 React 文本，模型生成的标签、链接或指令一律不执行。
- 原始隔离 iframe 与译文视图分离，不破坏当前 CSP、链接确认和图片显示策略。
- 未来如需保留 HTML 排版，应按本地文本节点/稳定 ID 翻译并严格校验替换映射，
  不能把模型返回的整页 HTML 当作可信内容。

## 5. 任务、限流与结果完整性

- 首期采用非流式，不提供 SSE。
- 同进程最多 1 个公网翻译任务，重复提交由 UI 门禁阻止；额外并发返回忙，
  未实现共享在途任务。成功缓存可避免之后的重复请求。
- 429/5xx/网络错误只给安全提示，不自动重试，不编造官方限额；未做 Retry-After 倒计时。
  格式兼容仅处理完整 JSON 围栏/已闭合前导思维包装；非结构化 stop 输出最多降级为两个单字段调用，
  不对截断、坏 HTTP 或不完整包装扩大请求。
- 连接 10 秒、响应头 60 秒，任务整体 120 秒，前端 IPC 兜底 125 秒。
- 长正文按段落/句子切片，限制单片/单任务字节、块数与输出预算；
  正文最多 32 KiB、标题 4 KiB、HTML-only 输入最多 2 MiB/20,000 个解析事件，
  每片至多 2,000 Unicode 字符、至多 16 片，单片输出预算 4,096 token。
  这些是客户端防护，不是官方限额；上游响应最多 256 KiB，成功正文最多 128 KiB。
- 不静默截断输入。空输出、非 JSON、缺少 content、`finish_reason=length`、
  不完整思维块或分片失败均不当完整成功，也不写入成功缓存。
- 请求关闭推理，不显示 reasoning_content；异常 `<think>` 输出需严格处理，
  不能盲目删除正文中任意位置的同名标签后宣称翻译正确。
- 邮件本身是待处理数据，不能据模型输出执行工具、读取凭据、修改邮件或访问它建议的地址。

## 6. 阅读切换与本地缓存

- 当前 MailReaderTransition 按选择挂载单页；翻译入口仅作用于选中且完整缓存的邮件，
  确认窗也绑定打开时的邮件快照，不会切换后自动对另一封发起请求。
- 切换邮件、目标语言或关闭阅读页时取消当前请求；结果必须绑定
  accountId、mailId、正文摘要、目标语言、provider/model 与提示模板版本，
  不能把上一封的迟到结果显示到下一封。
- 取消停止本机等待/展示，不等于撤回服务方已经收到的正文，隐私说明不能作此承诺。
- 成功译文缓存位于 `Config.DataDir/translations/`，不另设固定 C 盘目录，无需数据库迁移。
- 打开邮件会调用只读本地缓存快照，不命中也不请求第三方；命中时恢复工具栏开关、先显示原文。
  当前目标与标题/正文摘要必须匹配，迟到缓存不能覆盖用户刚完成的操作。
  后续安装器的数据位置设计应包含该目录。
- 文件名只用摘要/内部标识，不把邮件主题/地址当路径；权限与保护沿用用户数据目录。
  译文也属于邮件私有内容，不输出到日志或异常中。
- 不再复制一份原文到缓存；正文变化使摘要失效。缓存有容量/清理边界，只保存完整成功结果。
- 缓存文件至多 1 MiB，最多 128 条/16 MiB，写入时按旧文件时间清理；
  缓存失败仍可展示已生成译文，并明确提示未保存，不把部分译文写为成功。
- 日志只记录安全状态码、耗时等必要诊断，不记录正文、译文或完整上游错误体。

## 7. 首期设置与边界

- 邮件翻译服务：B 站 Index-Translate 免费公网服务（明确第三方及可用性限制）。
- 默认目标语言：简体中文；7 种白名单语言，不跟随 UI 切换悄悄改目标。
- 云端授权：默认未授权；不增加默认自动翻译。
- 本地缓存自动限量清理，仅删除派生译文，不删除邮件；首期没有单独的清理按钮。
- 不要求 API Key；将来接入需要 Key 的服务必须走系统凭据存储，不能复用邮箱密码字段。
- 首期不含附件 OCR、PDF/图片翻译、写信翻译、术语管理、批量后台翻译或自动转发。
- 对敏感邮件优先建议本地/受控服务，不把免费公网接口当成保密基础设施。
