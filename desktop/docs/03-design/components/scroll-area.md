# 滚动条占位与活动显示

> 状态：已实现，待评审 | 最后更新：2026-10-31
> 任务：[TASK-0065](../../07-tasks/active/TASK-0065-scrollbar-activity-visibility.md)

## 显示规则

- 默认透明，始终保留槽位，不通过切换宽度或 display 造成内容横向跳动。
- 鼠标进入**滚动条窄槽**才淡入；悬浮正文、列表内容、按钮或仅保持焦点不显示滚动条。
- 实际滚动（滚轮、键盘、触控、程序滚动）立即显示，800ms 没有新滚动后淡出；
  若指针仍在槽内或正在拖拽，则保持可见。
- 淡入/淡出沿用 `--scrollbar-fade`（160ms）及主题颜色；减少动态效果时不执行视觉过渡。
- 不需要滚动时不显示滑块；无上下箭头/增减按钮，不增加额外 Tab 焦点。

## 自定义 ScrollArea

- 外层负责固定 `--scrollbar-reserve`（12px）占位，视口隐藏原生条，透明轨道保持命中。
- 只有轨道 `:hover`、`data-scrolling=true` 或 `data-dragging=true` 可显示覆盖滑块。
  不能使用整个 root 的 `:hover` / `:focus-within` 作为显示条件。
- 拖拽使用指针捕获；释放、取消、丢失捕获时结束并保留短暂活动缓冲。
  右键不开始拖拽，触控拖动滑块时不触发浏览器接管手势。
- 滚动监听继续转发业务 onScroll；活动定时器在卸载时清理。
- 可选 `edgeFade` 用于邮箱列表和邮件列表：内容视口使用 CSS `mask-image: linear-gradient(...)`，
  依据实际 scrollTop/剩余高度分别开启 16px 顶部/底部透明过渡；无溢出或到达相应首尾时保持完整内容。
  mask 不加到外层，因此不影响窄槽轨道、拖拽或 Portal 浮层；不使用背景遮挡伪元素。
- 邮件列表外层保留尺寸、容器查询和分栏边框，内层具名 region 是可聚焦的真实滚动视口；
  继续在此视口转发无限加载，重试后焦点返回此处。追加邮件不重挂载，查询范围切换才重置。

## 原生滚动区域

- 阅读区、添加向导、撰写、可滚动提示/状态浮层与小确认框声明 `data-native-scrollbar`；
  textarea 自动采用相同策略。不得为了改滚动条而重挂载邮件阅读器、改无限加载或重置滚动位置。
- 应用级 `useNativeScrollbarActivity` 使用被动捕获 scroll/pointer 监听，不拦截输入。
  活动只属于实际滚动的元素，不冒泡污染外层或重复接管自定义视口。
- 槽位命中依据 `offset/client` 尺寸、边框与指针坐标，兼容 RTL 左槽、水平槽和缩放；
  不把整个容器、边框或无溢出的空槽视为显示条件。
- 离开文档、进入正文 iframe、窗口失焦/缩放以及卸载时撤销悬浮；
  原始 HTML 的 iframe 隔离、内部禁用滚动条与安全策略不变。
- Chromium/WebKit 使用无按钮的滚动条伪元素，滑块颜色由注册的 `<color>` 属性驱动过渡。
  标准 scrollbar-width/color 需在该分支成对设为 auto，否则会覆盖无箭头样式。
  其他浏览器保留标准透明/细条兜底；macOS 原生 WebView 未据 Chromium 验证冒称通过。

## 已验证范围

单测覆盖活动重置、定时器清理、独立嵌套滚动、内容/槽位命中、RTL、缩放、水平槽、边框、
无溢出、触控、失焦/缩放和离开清理。

Chromium 验证时显式取消自动化默认的 `--hide-scrollbars`，实际核对原生拖动、无箭头、
颜色中间帧和稳定占位；另覆盖自定义拖拽、键盘/滚轮、textarea、正文 iframe、
亮暗主题和减少动态效果。结果及平台边界以任务记录为准。
