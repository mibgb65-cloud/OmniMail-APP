## 模板

```markdown
# ADR-XXXX 标题

> 状态：提议 | 已生效 | 已废弃（替代：ADR-YYYY） | 最后更新：YYYY-MM-DD
> 决策人：@xxx

## 背景
问题是什么，约束是什么（性能/体积/团队能力/平台）。

## 备选方案
### 方案 A：...
- 优点
- 缺点
### 方案 B：...
- 优点
- 缺点

## 决策
选了哪个，一句话理由。

## 后果
- 正面：...
- 负面：...（接受的风险）
- 触发重新评估的条件：...
```

## 评审规则

1. 影响 ≥ 2 个模块或不可逆的决策必须写 ADR。
2. ADR 由提议人起草，架构负责人 review，合入后状态改为 `已生效`。
3. 推翻旧决策时：新 ADR 生效 + 旧 ADR 状态改为 `已废弃（替代：ADR-XXXX）`，不删除正文。
