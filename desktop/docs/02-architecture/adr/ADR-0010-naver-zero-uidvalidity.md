# ADR-0010 NAVER 显式零 UIDVALIDITY 的保守兼容

> 状态：提议（用户已确认方案，实现待评审） | 最后更新：2026-10-31
> 关联：[TASK-0066](../../07-tasks/active/TASK-0066-naver-sync-sidebar-layout.md)

## 背景与证据
真实 NAVER 连接中，TLS 登录及 EXAMINE/STATUS/SELECT 均成功，服务器在三者中明确返回
`UIDVALIDITY=0`，而 UIDNEXT 为非零。该值不符合标准 UIDVALIDITY 的正整数约定。
当前 IMAP 库将字段缺失与明确零值都解码为零；反复重试 SELECT 不能解决。

## 备选方案与决策
- 拒绝所有零值：最严格，但实际账号永远无法同步。
- 将零映射为常量或沿用旧身份：会虚构服务器未提供的纪元，拒绝采用。
- **限定官方 NAVER、明确区分存在性、原样保存零，并降级为保守只读同步**：本轮采用。
  用户已授权数据库迁移和备份；不扩展至任意服务商。

## 兼容边界
1. 仅官方 `imap.naver.com` 的隐式 TLS 会话可确认显式零值；TLS 验证不降级。
2. 选择期间观察有界响应行，跳过 literal，观察结果不包含在日志中；
   字段缺失、互相冲突、越界或不可可靠识别的帧均不能作为零值身份。
   完整正整数路径与原有 STATUS/SELECT 补取策略保持。
3. 服务层必须同时得到零值和协议适配器的显式确认，不能只凭数值放宽。
   仓储和数据库触发器再次限定 NAVER、官方主机、993 端口及隐式 TLS。
4. 零值邮箱不把历史最高 UID 当可靠增量边界，使用可恢复的分段摘要轮转核对。
   同 UID 的 Message-ID、主题、地址、时间或大小改变时事务替换实例，
   旧本地 ID、正文和附件引用同时失效；已读/星标变化不清正文。
5. 待补正文先核对头部；下载前后再次比对不可变摘要。
   身份变化不把正文保存到旧实例，仍可离线读取的缓存表示最后一次已核对快照。
6. 初始交付拒绝全部远端写入。TASK-0068 按用户要求增加下述受核验的已读能力；
   零值星标和 MOVE 继续返回 `ACTION_UNSUPPORTED`，不发出 MOVE/CLOSE/EXPUNGE。
   其他邮箱保持原能力。

## TASK-0068：受核验的已读／未读
- 仅 SetRead 可以申请可选的 `MailVerifiedReadSession`；服务再次核对 NAVER 官方
  主机、993 端口和隐式 TLS。没有该能力、账号端点已变更时不能绕过零值保护。
- 同一连接 SELECT，必须观察到显式零值；写前逐项比对完整不可变摘要，
  Message-ID 必须非空、长度/字符有效；无法核验的邮件不发 STORE。
- 仅 `+FLAGS`/`-FLAGS` 修改 `Seen`，不使用覆盖全部标记的 FLAGS=，不改星标或其他标记。
  校验服务器 UID/FLAGS 回执，随后再次核对完整摘要和最终 Seen。
  tagged OK 没有 FLAGS 时仍需独立 FETCH 确认，不能仅凭 OK 宣布成功。
- 写前身份不符不执行；写后断线、回执/身份/最终状态不符返回 `ACTION_UNCERTAIN`，
  不自动重试。服务器确认后，再在本地短提交锁内确认旧实例未被替换，才更新本地状态。
- 自动已读与工具栏已读/未读共用此路径，失败保留正文；不支持及不确定提示适用于各类操作，
  不再把标记错误描述成“没有目标文件夹”。

## 迁移与恢复
- 新增 schema v5，历史脚本与校验和不变；复用 `VACUUM INTO` 生成含已提交 WAL 数据的
  `backups/pre-migration-v0005-*.db`。备份失败中止升级。
- 事务内建立完整新外键链、复制正文和附件引用，再从子表向父表替换；
  失败回滚结构、数据和版本，不关闭外键约束，不直接改写 sqlite_schema。
- 自动降级不支持。需要回退时先关闭所有实例、保留现有 v5 数据与附件目录，
  再按明确恢复授权将迁移前备份恢复到原数据库位置；升级后新增邮件不在旧备份中。
  不可用旧二进制直接打开 v5，也不能在应用运行时仅复制主库忽略 WAL。

## 剩余风险
零值服务端不提供可靠纪元。如果服务器同时复用 UID 和全部不可变摘要，客户端无法仅凭这些
协议字段证明是另一封邮件；前后校验也不构成远端事务。该方案降低常见错配风险，
不宣称具备标准 UIDVALIDITY 保证。TASK-0068 的同连接核验降低常见误标风险，
但服务器在最后一次核验与 STORE 之间复用 UID 仍不能由客户端完全排除；更严格保证、
零值星标和移动须另行设计，不能把已读例外扩大为通用写入许可。
被替换实例的历史孤立附件文件沿用既有 GC 限制，不把引用删除称为磁盘垃圾回收。
