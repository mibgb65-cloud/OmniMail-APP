## 用例编号规则

`TC-<模块>-<3位序号>`，模块：`ACC` 账号、`MAIL` 邮件、`SYNC` 同步、`CMP` 撰写、`SRCH` 搜索、
`UI` 界面、`PLAT` 平台、`DB` 数据。示例：`TC-ACC-001`。

## 单条用例格式

```markdown
### TC-SYNC-003 断网恢复后自动继续同步

- 级别：P0
- 前置：账号 ACCOUNT_ID 已添加并完成首次同步
- 步骤：
  1. 断开网络 30s
  2. 恢复网络
- 预期：
  - 10s 内状态从 `backoff` 变为 `syncing`
  - 同步完成后 `lastSyncAt` 更新
  - 无重复邮件行
- 自动化：`TestSyncReconnect`（in progress）
```

- 修复缺陷必须在对应用例文件追加"回归用例"，并在用例中标注关联的 BUG 编号。
