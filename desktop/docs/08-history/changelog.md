## 记录规范

| 规则 | 说明 |
| --- | --- |
| 面向用户 | 用用户能理解的语言，不写内部函数名 |
| 按影响分类 | 同一版本内按 新增 → 变更 → 修复 → 移除 → 安全 排列 |
| 链接引用 | 功能条目引用 `FEAT-` 或 `TASK-`，缺陷引用 `BUG-` |
| 破坏性变更 | 单独用 `**破坏性**` 标注并说明迁移方式 |
| P0/P1 修复 | 必须记录，并附回归用例编号 |

示例条目：

```markdown
### 修复
- 修复断网后标记已读无法回写的问题（`BUG-20261020-03`，回归：`TC-SYNC-007`）
```
