## 0. 编号与优先级

- 需求编号 `FR-xx`；优先级 `P0` 必须（阻塞发布）/ `P1` 重要 / `P2` 可选。
- 每个 P0/P1 需求必须有对应的**验收标准**，且可被测试用例（`TC-`）覆盖。
- 状态：`已提出` → `已评审` → `开发中` → `已验收`。

## 1. 账号管理（FR-01）

| # | 需求 | 优先级 | 说明 |
| --- | --- | --- | --- |
| FR-01-1 | 添加 IMAP/SMTP 账号 | P0 | 手动填写主机/端口/加密方式；保存前做连通性校验 |
| FR-01-2 | 服务商预设 | P1 | Gmail/Outlook/QQ/163/iCloud 等自动填充参数 |
| FR-01-3 | OAuth2 授权 | P1 | Gmail、Outlook；刷新令牌存系统钥匙串 |
| FR-01-4 | 多账号统一收件箱 | P0 | 按时间合并；账号着色标识 |
| FR-01-5 | 账号启用/停用、移除 | P0 | 移除时可选是否删除本地数据 |
| FR-01-6 | 凭据安全存储 | P0 | Windows Credential Manager / macOS Keychain，禁止明文落盘 |

**验收（FR-01-1）**
- 输入错误端口 -> 明确错误文案 + 不落库。
- 校验成功的账号 5 秒内开始首次同步，并在 UI 显示进度。

## 7. 非功能需求（NFR）

| 类别 | 指标 | 备注 |
| --- | --- | --- |
| 性能 | 冷启动 ≤ 1.5s；列表滚动 60fps；搜索 P95 ≤ 120ms | 见 [测试策略](../05-testing/testing-strategy.md) |
| 内存 | 3 账号常驻 ≤ 250MB | 附件解码不得全量入内存 |
| 体积 | Windows 安装包 ≤ 25MB | Wails + WebView2 引导 |
| 可靠性 | 崩溃率 < 0.5% 会话；崩溃后重启不丢草稿 | |
| 安全 | 凭据进系统钥匙串；HTML 邮件默认禁远程资源 | 见 [ADR-0005](../02-architecture/adr/README.md) |
| 兼容 | Windows 10 1809+ / macOS 12+ | 不支持 Linux（v1） |
| 可访问性 | 键盘可完成主要流程；对比度 ≥ 4.5:1 | [设计系统](../03-design/design-system.md) |
| 国际化 | v1 中文 + 英文 | 文案外置，不硬编码 |
