# 编码规范

- Go 服务处理本地能力；React 组件处理呈现和交互。不得通过前端直接保存邮箱凭据，也不得把邮箱数据写入日志。
- 绑定方法是输入校验边界。新增输入应定义类型、格式和长度，验证失败时只返回对用户有用且不含敏感数据的信息。
- Go 用 gofmt，前端使用严格 TypeScript、ESLint 和 Prettier。可用 `task format` 统一格式化。
- 前后端手写代码文件（含 `.go`、`.ts`、`.tsx`、`.css` 等）单个不超过 200 行；目录结构采用按业务模块和职责分层的树状文件夹设计，合理拆分组件、状态、样式与数据定义。
- 手写源码使用 UTF-8 无 BOM；生成绑定不作为手写代码修改。
