# OmniMail v0.0.1 · 首个正式生产版发布

> **发布日期**：2026-11-27 · **发布通道**：`Stable`（正式生产版） · **适用平台**：Windows 10 / 11 (x64)

## 核心更新亮点

- **18+ 多源邮箱与智能体工作台开箱即用**：原生内置 **Linux.do 社区邮箱**、**Meta Muse (`@muse.ai`)** 与 **腾讯 WorkBuddy** 智能体邮箱工作台，完整支持 Gmail / Outlook / QQ / 网易（`RFC2971 ID`）/ iCloud / Yahoo / Yandex / Naver 等 8 大个人邮箱、6 大主流企业邮（腾讯/阿里/网易灵犀/飞书/263/Zoho）及通用 DNS MX 自动识别。
- **100% 本地优先与纵深安全基线**：无云端账号体系、零遥测上报；支持多本地空间物理隔离、Argon2id PIN 锁、Windows DPAPI 凭据加密（`secrets.vault`）、`bluemonday` + CSS AST 白名单沙箱、外链追踪图/CSS 背景图默认拦截与无损可逆还原、SPF/DKIM/DMARC 三段式反钓鱼预警。
- **免 Key 保真翻译 & 5 步 `PrivacyGuard` AI 助手**：内置免配置原文/译文/双语对照流式翻译（保留原邮件表格与按钮排版）；支持 OpenAI、Claude、Gemini、DeepSeek、本地 Ollama 与自定义兼容端点 BYOK 接入，强制执行敏感验证码邮件硬拦截、PII 脱敏与零附件上传。
- **双连接高性能同步与防误发发件队列**：纯 Go 零 CGO 单体架构（安装包仅 ~7.4 MB），采用 `workConn + idleConn` 双连接实时推送、SQLite WAL + FTS5 毫秒级全文检索、Zstd 内容寻址压缩归档，提供发件身份锁定、5/10/20s 零网络真撤回发送与跨重启定时发信。
- **现代精雕桌面体验与静默自更新**：支持中英双语即时切换、GPU 可中断亮暗扩散主题过渡、离屏 Canvas 智能衬底图片 Lightbox、30 天干跑预览规则引擎、`.ics` 日程冲突检测与一键 RSVP，以及 Stable / Beta 双通道后台 SHA-256 强校验 NSIS 静默升级。

## 安装与校验说明

- **Windows 64 位安装包**：`OmniMail-windows-Setup-v0.0.1.exe`
- **完整性校验清单**：`SHA256SUMS.txt`（随同本版本 Release 资产自动附带，客户端后台升级时自动执行强校验）
- **运行要求**：64 位 Windows 10 / Windows 11（内置 Microsoft Edge WebView2 Runtime）
- **升级提示**：安装向导支持将程序目录与本地邮件数据目录分离存放；覆盖升级或卸载默认完整保留本地空间邮件数据。
