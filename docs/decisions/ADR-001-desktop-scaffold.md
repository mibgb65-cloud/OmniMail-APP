# ADR-001：桌面脚手架与构建路径

状态：已采纳（2026-11-20）

## 背景与备选

OmniMail 需要参考 OmniProxy 的桌面工具链与开发流程。完整复制会同时引入不相关的网关、存储和发布配置；只初始化裸 React 则不会验证原生桥接和内嵌资源。

## 决定

从 Wails v3.1.0 官方 React + TypeScript 模板起步。保留当前仓库的 `desktop/` 布局，在根目录提供 Taskfile 和文档，复用 OmniProxy 的任务记录与统一验证思路。不启用实验构建，不复制业务代码。

## 影响

开发版与未来发布版边界明确。Wails 绑定在本地和 CI 重新生成，任何绑定变更须通过类型检查和内嵌构建。Windows 先验证；其他平台和发布流程需要独立验证。
