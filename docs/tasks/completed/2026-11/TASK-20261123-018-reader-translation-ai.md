# TASK-20261123-018 邮件阅读器翻译与跨语言 AI

状态：Completed

## 范围与方案

- 阅读器在标签与删除之间常驻翻译入口，窄宽度优先保留。使用锚定浮层选择语言、显示模式和主题选项，翻译后在顶部切换原文、仅译文和双语。
- 当前仓库没有独立免费翻译引擎。复用已配置的模型请求通道，不新增未授权的外部端点；请求前明示范围。后端从当前邮件提取文本片段，不传 HTML、图片及附件。前端在现有安全渲染链路替换文本，保留原邮件布局和安全规则。
- 移除 AI 重复翻译入口；AI 始终分析原文，摘要及关键信息按界面语言输出，草稿按原邮件语言输出。默认侧栏宽度调整为 336px，保留现有调宽能力。

## 验证计划

- 核对本地设计稿的首页和翻译画板，补充工具栏宽度、语言和片段映射、后端隐私与模型回包校验。运行 `task verify`，不启动桌面程序、不提交或打包 Beta。

## 实施与验证

- 读取本地 `.fig` 的首页及亮、暗色翻译节点，参照亮色画板核对工具栏、横幅和四栏关系。共用阅读器入口始终保留，选项通过 Portal 锚定到按钮，外部点击或 `Esc` 关闭。按需求只显示中性的「翻译」徽标。
- 模型只接收从同一工作空间、当前邮件提取的文字片段和可选主题。译文回包数量不一致或引擎失败时保留原文。显示模式可在当前会话中立即切换，不重新请求，也不重建邮件 HTML 或重新加载图片。
- 独立 Omni AI 栏采用默认 336px 并兼容用户调宽；摘要与关键信息使用界面语言，回复草稿使用原邮件语言，支持换语气并插入快捷回复框。
- `task verify` 和 `git diff --check` 通过；13 项前端用例、Go 测试、类型检查及开发 EXE 构建通过。邮件翻译请求使用本地模拟模型端点验证，未启动 Windows 应用做手工复验，也未提交或打包 Beta。
- 当前复用用户配置的模型，不提供零密钥免费引擎；译文只缓存于当前工作空间会话。默认目标语言、显示模式与主题偏好保存在本机。
