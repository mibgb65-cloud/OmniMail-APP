# TASK-20261123-015 通用 UI 图标迁移至 Heroicons Outline

状态：Completed

## 范围与依据

- 依据本地 `OmniMail-redesign.fig` 的 `heroicons:*` 标注，迁移导航、工具栏、AI、设置、弹窗及交互状态的通用图标。
- 保留各位置的图标显示尺寸和辅助文案，不修改 OmniMail 标志、开屏品牌徽记或邮箱服务商品牌资产。

## 方案与验证

- 固定官方 `@heroicons/react` 依赖，在共享入口显式映射 24 Outline 组件并收紧图标名称类型；去除旧手绘图标路径。
- 保留原有动效；在加载进度环上继续使用独立的动画几何，成功、失败符号使用官方轮廓。
- 检查实际输出的 SVG、全站编译和品牌文件未变，运行 `task verify`。保留已有滚动改动，不启动应用、不提交、不打包。

## 实施结果

- 本地解析新版 `.fig` 的图层，读取 89 种 `heroicons:*` 名称作为映射依据。固定 `@heroicons/react@2.2.0`，共享 `Icon` 仅静态导入官方 24 Outline，保留显示尺寸、主题色和按钮辅助文案。
- 按场景区分写邮件、写信设置、草稿、附件和安全警示图标。添加按钮使用官方 `PlusIcon`，星标保持轮廓并以主题背景及 `aria-pressed` 标示状态；异步反馈保留进度环动效，成功和错误符号改为官方轮廓。
- 删除原自绘通用图标路径表。应用标志、启动棱镜和邮箱服务商图片不变。

## 验证与交付

- `task verify` 通过，包含 5 个前端用例、类型检查、Go 测试和 Windows 开发 EXE 编译。新增用例核对所有注册图标的 `24×24`、`1.5` 描边、无填充及典型设计映射。
- 已更新[技术栈](../../../architecture/TECH_STACK.md)、[编码规范](../../../development/CODING_RULES.md)和[测试说明](../../../development/TESTING.md)。通过 Git 差异核对品牌资源和品牌组件未变。
