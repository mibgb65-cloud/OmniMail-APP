# TASK-20261123-021 修复邮件卡片「AI 已摘要」标签

状态：Completed

## 范围与方案

- 邮件列表原来只读取加载时的摘要标记，并且遇到其他状态标签时会隐藏摘要标签。改为同时使用已保存的分析结果，让生成完成后对应卡片立即显示紫色「AI 已摘要」，且与其他状态并列。
- 摘要和列表标记一起写入 SQLite；以已保存的非空摘要兼容旧版漏写标记的邮件，不将只做过问答或翻译的邮件标为已摘要。
- 用本地模拟模型和 SQLite 验证列表返回、旧摘要兼容与事务回滚，运行 `task verify`。不启动应用、不提交、不打包 Beta。

## 实施与验证

- 邮件卡片读取局部摘要缓存或持久化标记，摘要保存后无需刷新就会在右下角显示完整的「AI 已摘要」。其他状态不会覆盖该标签。
- 摘要和列表标记在同一个事务提交。列表兼容已保存但漏写标记的旧摘要，问答占位和损坏 JSON 不触发标记。
- `task verify`、`git diff --check` 通过；覆盖完成摘要后列表标记、旧摘要、问答占位、损坏数据与事务回滚。已生成开发版，未启动 Windows 桌面应用手工复验，未提交或打包 Beta。
