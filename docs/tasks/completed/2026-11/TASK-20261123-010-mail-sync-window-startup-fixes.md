# TASK-20261123-010 邮件阅读、首次同步与窗口启动修复

状态：Completed

## 需求与范围

- 默认允许外部资源时不显示常规拦截提示；保留高风险邮件的安全拦截。
- 新增邮箱后的同步弹窗不显示设计稿数据，只渲染对应账户的真实进度。
- 修复退出后启动时窗口显示异常，以及从托盘真正退出后重新启动不播放开屏。
- 本轮提交修复，并构建 Windows x64 Beta 生产安装包供本地更新；不重跑测试、不安装、不启动应用、不推送。

## 方案与预期验证

- 让阅读器根据后端的有效远程图片策略展示提示，并检查配置切换后的正文刷新。
- 使用后端同步状态区分等待、处理中、完成与失败，按账户隔离，不重复触发自动启动的同步。
- 检查 Wails 窗口几何与 WebView2 首次显示的时序，让前端区分正常启动和静默驻留。
- 补充相关回归测试，运行 `task verify`；Windows 窗口和托盘实机场景记录为手工复验项。

## 实际改动

- 后端在邮件详情返回实际图片放行状态，前端用它决定是否显示常规拦截提示。设置写入成功后重新加载当前正文；高风险邮件及会话中的高风险子邮件仍拦截图片。
- 删除首次同步的设计稿占位数据及弹窗的重复拉取。连接、文件夹扫描和收件箱批次由同一个后台 worker 推送，前端按账户缓存最近一条进度；收件箱批次处理完不等同于整轮同步完成。
- 规避 Wails Windows 在 `StartState` 最大化后继续应用普通坐标的顺序：普通几何先应用，WebView 运行时就绪后恢复最大化。冷启动开屏在页面可见后开始计时，不再根据初始化时的短暂隐藏跳过动画。
