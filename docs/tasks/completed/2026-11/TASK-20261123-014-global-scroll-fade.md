# TASK-20261123-014 全局隐藏滚动条与智能底部渐隐

状态：Completed

## 范围

- 隐藏应用原生滚动条，归零占位，清除旧轨道和滑块样式。保留滚轮、触控板及键盘原生滚动。
- 为工作台三栏、设置、弹窗、抽屉及其他应用自管的纵向视口统一提供随主题变化的 30px 底部渐隐。

## 方案与验证

- 使用公共容器保留滚动视口及内容层，用尺寸观察和原生滚动事件维护状态。渐变是固定在视口底部的独立装饰，不占高度、不接管输入。
- 保持紧凑态与所有固定区域的高度约束，保留邮件翻页、切换邮件回顶与表单交互。Shadow DOM 补齐滚动条覆盖；外部查看器不伪造滚动状态。
- 测试溢出判定、滚动与尺寸变化、监听器清理，运行 `task verify`。不启动桌面应用、不提交、不打包。

## 实施结果

- 全局使用 `scrollbar-width`、WebKit 和旧内核的无占位规则，删除旧轨道、滑块和颜色令牌。邮件列表横向内边距在各断点左右对齐，邮件 Shadow DOM 补齐隐藏规则。
- 工作台、设置、弹窗、抽屉、下拉、引导、文本预览和原生文本域都使用统一的渐隐机制。渐变取自面板背景令牌，不影响指针、文本选择或滚动；两像素阈值内隐藏，减少动效模式不做淡入淡出。
- 用原生滚动事件与 `ResizeObserver` 观察视口及内容，动画帧内合并更新。保留邮件列表分页和阅读区切信回顶，原生文本域也响应输入与程序写入。浏览器内置 PDF 查看器属于独立文档，保持原交互。
