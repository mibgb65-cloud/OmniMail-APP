## 方案与验证

- 在 Go 统一校验端点和凭据，官方模式强制固定地址；已有网关密钥不得跟随地址变更。模型查询使用厂商协议，不记录或返回明文密钥。
- 前端隔离每次提供方切换后的表单和异步请求；官方列表用下拉选择，兼容端点手填仍可保存。
- 使用离线 HTTP/端点隔离测试、类型检查与 `task verify`，记录真实 Windows 与付费官方 API 的手工复验项。不启动应用、不提交、不打包，保留现有改动。

## 实施结果

- 本地解析 `.fig` 原始节点，参照首页两种主题中的 `AccLeft` / `AccRight` 对齐、46px 行高和 28px 徽标，以及 AI 服务画板中的提供方 / 密钥 / 模型 / 操作栏顺序和独立自定义模式。侧栏在宽屏、笔记本和窄屏抽屉均使用同一结构。
- 官方预设隐藏 Base URL，展示只读地址和脱敏密钥，可拉取、搜索和选择真实模型；自定义与 Ollama 支持免密、手填模型及可选辅助拉取。切换提供方清除未保存的表单与上一家的模型列表。
- 新增模型查询和密钥掩码 IPC，覆盖 Bearer、Anthropic 和 Gemini 协议。后端在查询、测试、保存与正式对话时强制官方端点，网关密钥按端点隔离且只在 HTTPS 或本机回环上传输；连通性测试不写入配置。
